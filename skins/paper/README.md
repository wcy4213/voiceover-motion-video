# 皮肤 · 分析师手账（投教线，2026-08 立线）

暖米白纸底 + 墨字 + 荧光笔 + 红笔 + 印章的"纸面"皮肤，目标观感是**一页值得收藏的分析师笔记**（藏赞比是这条线的北极星）。与投研线的黑底点阵刻意区分——新开内容线，观众一眼要能认出"这不是投研条"。适合方法论/概念投教（如何看财报、股息分红、聪明钱怎么读）。

## 视觉语言

- 底：暖米白纸 `#F2EFE8` + feTurbulence 纤维噪点 + 微暗角（`PaperBackdrop`）
- 字：墨黑 `#1A1A1A`；品牌黄 = **荧光笔涂层**；品牌紫 = 章节索引标签/图形主色
- 涨绿 `#0B8043` / 跌红 `#C5221F`（浅底加深一档，别用深色皮肤的那对）
- 图形语言：纸卡拍落、拍立得+图钉、荧光笔扫过、红笔手绘圈、印章砸下、便签斜贴、索引标签
- 转场：大章**翻页**（`PageFlip`），小节硬切
- 画布参考：1080×1440（竖版笔记感）

## 封面铁律（这条线独有）

**不用**黑底实拍开场（那是投研线的皮肤，换皮肤不换封面=没换）。正解:

- **纸面封面 + 实拍收进拍立得窗口**（相纸+图钉，窗口里播 keynote 实拍）——既满足"首帧有真人+日期+排版完整"，又保住实拍的运动感
- frame 0 完整静止（日期章+栏目章+真人+大标题+钩子）；冲击动画从 frame 1 起：纸面 punch-in + 震屏 + 纸屑爆 + 红笔圈画出 + 荧光笔扫过 + ✓逐个打勾，**元素不重新入场**
- ⚠️ frame 0 必须"完整"的元素，冲击动画**不能用归零型手法**（strokeDashoffset 从 0 画出 / 从 0 淡入缩放）——`f === 0 ? 1 : tick` 会让元素在 frame 1 消失、几十帧后重画，开头闪一下。只能用 scale/位移/颜色变化这类不影响可见性的手法
- 非突发选题用中性栏目章（紫底「财报季 · 方法论」这类），不用红 BREAKING
- 封面留白用信息填（三连✓卡），别留大片空纸

## 其他实战规则

- 开篇"涨的涨跌的跌"配**自绘行情滚动列表**当背景（涨绿跌红交替、价格每 7 帧微跳、整列匀速上滚）。**必须代码自绘**：第三方行情 App 截屏带台标水印，自家产品界面在国内平台触"禁产品界面/交易演示"红线。屏四边留 22px 纸边保住手账身份
- 表现"钱"用 💵/💰，别用 🪙（灰银色，小尺寸读作石头）
- 文字密度同黑皮肤铁律：标题 ≤6 字、卡片正文 ≤8 字、手写句 ≤7 字；字少之后字号放大一档
