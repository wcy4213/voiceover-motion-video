# 决策引擎：内容 → 形式 → 手法（自主判定，不用每次问用户）

> 目标：拿到一个选题/一段口播，agent 自己判断"这条该做成什么样、每一句该用什么画面和剪辑手法"，然后把判断写进【制作单】和分镜表给用户过目。
> 判断分两层：**整片层**（格式 × 皮肤 × 主技术 × 平台）和**镜头层**（每一句口播的画面功能 → 具体手法）。
> 用户明确指定的（"做成纸面""参考上次那条""用 3D"）永远覆盖本引擎的推荐。

---

## 第 1 层 · 内容画像（8 个维度，每条片子开工时打分写进制作单）

| 维度 | 取值 | 怎么判断 |
|---|---|---|
| D1 意图 | 告知(突发) / 解释(机制) / 判断(观点) / 叙事(故事) / 教程(怎么做) / 展示(产品) / 娱乐(梗、情绪) / 追踪(资金、传导) | 看口播最后一句想让观众带走什么 |
| D2 时效 | 小时级 / 周级 / 常青 | 有没有"今天/这周"的事件钩子 |
| D3 抽象度 | 实物（产品/人/工厂）/ 数据 / 概念（机制、术语）/ 关系（因果链、资金流） | 主语是能拍到的东西，还是只能画出来的东西 |
| D4 数据形态 | 无 / 一个关键数 / 时间序列 / 构成占比 / 多方对比 / 排名变化 | 口播里的数字是怎么用的 |
| D5 主角 | 具名人物 / 公司机构 / 普通人（"你"）/ 无 | 能不能出真人 |
| D6 可得素材 | 官方实拍 / 新闻照片 / 产品截图·录屏 / 只有数据 / 什么都没有 | 先查 broll-pool 台账和官方频道 |
| D7 情绪基调 | 紧张 / 好奇 / 反差讽刺 / 轻松 / 庄重 / 惊叹 | 口播第一句的情绪 |
| D8 发布场景 | 抖音精华 / 小红书长版 / 视频号 / B 站 / TikTok·Shorts / YouTube 横版 / 投放 | 用户指定，否则按线别默认 |

### 2.1b 线别默认 vs 轮换（冲突时这样处理）

`rules/requirements.md` §0 的**线别默认皮肤**（投研热点 = 黑底点阵 1084×884；投教 = 纸面系 1080×1440；贴纸 = 方格纸）是用户定的默认值，**优先于本引擎的轮换推荐**。本引擎可以在制作单里**提议**换皮肤（写清理由 + 台账依据），用户在制作单确认时点头才换；用户没表态 = 用线别默认。金融以外的新题材（expand.md 1–3 圈）没有线别默认，按本引擎推荐，制作单里标"实验"。

### 2.3 抽象度 × 素材 → 主技术（一条片子定 1 个主技术 + 1–2 个辅技术）

| D3 抽象度 | 有官方实拍/照片 | 只有数据 | 什么都没有 |
|---|---|---|---|
| 实物 | **实拍**（开场 + 2–3 处）+ 3D 卡片承载截图 | 3D 重建（Card3D/Coin3D）| AI 生图/生视频（单独列需求清单，标 AI 生成） |
| 数据 | 实拍开场 + **数据可视化**（Candles/Ring/Bars3D/IsoCity3D/SplitFlap） | **数据可视化 + MG** | 同左 |

## 第 3 层 · 镜头级决策（每一句口播 → 画面功能 → 手法）

分镜时先给每句口播标一个**画面功能**，再按表选手法。同一功能相邻两次必须换手法。

| 画面功能 | 什么时候 | 首选手法 | 备选 |
|---|---|---|---|
| **认人**（谁） | 第一次提到人物/公司 | 实拍讲话片段 / 抠图 + 名牌 | 拍立得、Card3D 照片、logo + $代码药丸 |
| **砸数**（多少） | 一个关键数 | Hero 巨数字 / SplitFlap / Number3D | 乱码锁定（terminal）、Ring（占比） |
| **看变化**（涨跌/趋势） | 时间序列 | Candles 逐根生长 / 折线画出 | 时间轴横移 + 数字滚动 |
| **比大小**（谁多） | 对比 | 分屏对撞 / Bars3D | IsoCity3D、面积块、比例尺（"= N 个苹果公司"） |
| **看构成**（由什么组成） | 占比/拆分 | Ring / 华夫格 / 数字被切块 | 俯视拆解台把物件摊开 |
| **讲机制**（怎么运作） | 概念、因果 | MG 推演：Morph 变形、FlowLine 传导、角色演一遍 | 白板线稿、贴纸小剧场 |
| **追流向**（钱去哪） | 资金/供应链 | FlowLine + 地图 / Globe3D 弧线 | Particles3D 聚合 |
| **给证据**（凭什么） | 引用数据/文件/原话 | 文件特写 + 红笔圈 / 原声片段 + 冻结帧批注 | 打印件下滚、Card3D 截图 |
| **转折**（但是） | 反差、推翻 | 硬切 + Punch + 换底 / 模式打断（平面→3D、图表→实拍） | LiquidReveal、zoom-through |
| **情绪**（多惨/多疯狂） | 气氛 | 实拍蒙太奇 / KineticWords 关键词 slam | 光漏、颗粒、慢推 |
| **品牌位**（用 Bobby AI） | 前置位 + 3–4 处功能位 | BobbyCallout / Bobby 回答此刻在算的问题 | Card3D 截图（抖音可放信息查询类回答截图，不放交易界面；**小红书版不放任何 Bobby 界面**，见 rules §2D） |
| **结论**（所以呢） | 段尾/片尾 | 印章砸下 / 上升（rise 接缝）/ 留白大字 | 回环到开头画面 |

### 音乐版（TikTok / Shorts / YouTube / 投放）

音乐烧进成片时：先跑 `scripts/beat_grid.py` 拿强拍帧；大章节切点、Punch、巨数字落地、Stamp 全部吸到强拍（`--snap-frames`），位移 >0.6s 的切点改分镜不硬拉；每 2 小节（8 拍）至少一个画面事件。抖音/小红书不烧音乐，不适用。

### 剪辑手法 → 什么时候用

| 手法 | 用在 | 实现 |
|---|---|---|
| 速度峰值硬切（cut-the-curve） | 默认的场景间切换 | `Shot enter/exit="curve"` |
| 穿越推进 zoom-through | "往下钻一层"、展开细节 | `Shot exit="zoom"` |
| 反向拉远 | 揭晓、回到全局 | `Shot enter="pull"` |
| 匹配剪辑 match cut | 前后两场形状/位置相同（硬币→圆环、数字→数字） | 两场同坐标放同形元素 + 硬切 |
| 重音冲击 Punch | 口播重音、最大数字落地（配额 ≤1/分钟） | `<Punch at>` |
| 快甩 whip | 并列项切换（第 1 名→第 2 名） | `useWhip` |
| **共享元素** | 上一场的主体在下一场还要用（大数字→角落、logo→标题栏） | `Carry`（顶层，关键帧跨场景） |
| **缩成卡片** | 从细节回到全局、"这只是其中之一" | `NestZoom`（上一场延长，整屏缩成下一场一张卡） |
| **按幕换底** | 大章节切换、情绪换房间 | `ColorFlood`（放最底层，一幕一色） |
| 界面道具 | 产品/AI/工具题的"看这里" | `Cursor` 点一下 / `SelectionBox` 框住 / `Toggle` 拨一下 |
| 冻结帧批注 | 原声/实拍里的关键一刻 | 实拍暂停 + 红笔圈 + 箭头 |
| 分屏 | 对比（一边 ≥ 另一边 2 倍面积时才用） | 两个 Panel + 记分牌 |
| 蒙太奇 | 情绪段、"事情越来越严重" | 3–5 个实拍 0.6–1.2s 快切 |
| 模式打断 | 每 30–45s 一次 | 换主技术（2D→3D、图表→实拍、深底→浅底） |
| 光漏/液态揭示 | 大章节、情绪转换（≤1 次/章） | `LeakAt` / `LiquidReveal` |
| 回环 | 片尾接回开头（Shorts/TikTok） | 最后一帧构图 = frame 0 |

## 第 4 层 · 自检（引擎输出前过一遍）

1. 格式和皮肤跟台账最近 2 条不重复？
2. 主技术只有 1 个、辅技术 ≤ 2 个？（每场换一种特效 = 炫技，见 art-direction §2）
3. 每句口播都有画面功能？相邻同功能换了手法？
4. 3D 场景 ≤ 全片 1/4（渲染慢且抢戏），且至少 1 处（"惊叹/科技"情绪时）？
5. 素材降级到"AI 生成"的位置，单独列给用户确认了吗？
6. 合规：画面红线、话术黑名单、平台差异（`rules/requirements.md` §2E、平台合规自检清单）。

把以上结论按 **SKILL.md Step 3 的【制作单】模板**（唯一模板）填好，镜头功能写进分镜表「画面功能」列，一起发给用户，**用户点头再搭工程**（老闸门不变）。
