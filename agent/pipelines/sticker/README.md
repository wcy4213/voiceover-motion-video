# 贴纸动画投教视频（Bobbie 投教小剧场）

对标抖音「哆啦小课堂」验证过的形态：方格纸背景 + 角色立绘贴纸 + 道具随口播弹出 + 底部大字幕，60~90 秒讲透一个金融概念。

## 角色与人设铁律（写进每次分镜）

- **Bobbie**（紫青蛙，头戴蓝花，粉肚皮）= 散户/老百姓视角。不太懂金融、跟观众一起学习犯错；**永远不能是操纵者/收割方/资本**，只能当观察者、亲历者、被割方、恍然大悟者。
- **Rich**（紫独角兽，彩虹鬃毛+墨镜+白T）= 大鳄/资本/对手方。一切"割韭菜/操纵/设套/套利获利"的操作者。
- 脚本三段式：**提问钩子 →角色情景剧类比 → 一句话定义收尾**；名词必须包"利益冲突/被割/反直觉"的情绪外壳，纯中性讲解数据必扑（对标账号 59 条数据验证）。
- 直接商用他人 IP（哆啦A梦/Labubu）是侵权：素材"神似不形似"，生图 prompt 不写 IP 名。

> **2026-10-08 起总入口 `video-agent`**：贴纸线也先出【制作单】（格式选自 `video-agent/craft/formats.md`，贴纸线皮肤固定方格纸，变化靠格式与镜头）；成片加跑 `video-agent/scripts/pace_check.py` 节奏体检。

## 平台分发与包装（2026-07 双平台实测）

同一条《什么是「做空」》的双平台数据：抖音 2s 跳出 62.8%、人均观看 7 秒、涨粉 4；小红书收藏 45（账号全场第一）、涨粉 35、涨粉/观看 1.8%。执行：

- **投教贴纸片主投小红书**（吃收藏逻辑，转粉效率高于财报快讯类），周六上午 9~12 为候选发布槽位（待验证）；抖音是副阵地。
- **抖音版必须热点入题**：第一句绑当周正在发生的事件+硬数字（"XX 被做空暴跌 30%，做空到底是什么"），严禁"什么是 X"冷概念开场——推荐页 2 秒内给不出"为什么现在看"就被划走。
- **标题/封面禁用概念疑问句**："什么是「做空」？"实测小红书封面点击率 5.2%（约为账号财报条的一半）；改冲突悬念式（"Rich 半个月赚了 Bobbie 一年的钱，用的什么招"）。
- **提问/互动放前 30 秒** + 发布后置顶评论承接（结尾提问实测失效，只有 4~6% 的人听到）。
- 发布时机与数据回收表见 `agent/script/references/platform-douyin-xhs.md`。

## 关键技术规范（全部踩坑验证过，不可违反）

1. **Remotion 图片必须用 `<Img>` 组件**，原生 `<img>` 在并行渲染下随机缺帧 = 成片贴纸跳闪
2. **时间对齐用字级时间戳**（`scripts/force_align.py`：paraformer-zh 字级时间戳 + difflib 对齐脚本原文）；字符比例估算中段漂移可达 2 秒，只可粗估
3. **字幕规范**：白字 + 品牌紫描边（WebkitTextStroke 12px #6F00FF + paintOrder:stroke）、零动效瞬时切换、LEAD 提前 2 帧、对白走 SpeechBubble 气泡不进字幕轨、字幕禁止引号对白
4. **角色出场必带名牌**（Sticker 组件 name prop），注意别被道具压住
5. **文字压图必须像素级测量**：numpy 找目标区域连通域质心，换算显示坐标，禁止目测
6. **全片禁闪烁/脉冲**效果；带文字的道具（价签/SALE）一律代码渲染，AI 生图必乱码
7. **首帧防同质化**（抖音铁律）：frame 0 = 完整封面（日期 + 标题 + 角色全部可见），禁空底弹入
8. **交付前必跑跳闪 QC**：`ffmpeg -vf "select='gt(scene,0.06)'"` 找非切点突变帧，应为 0

## 素材生产规范

- 新增素材**合并成一张拼图**生成（2x2 或 1x2），省额度且同图一致性更好
- prompt 风格锚点：`clean bold ink outlines with slight hand-drawn wobble + bright saturated colors + chunky rounded cartoon proportions`，反向清单两头堵（禁 kawaii clipart / 禁 crosshatching 素描写实做旧）；角色/道具都带 `refs/style-card.png` 风格参考图
- 抠图用**边界泛洪**（`scripts/ingest_assets.py`）：只透明化与边缘连通的近白区，保住白 T 恤/白卡片（rembg 会误伤）；切拼图按连通域质心归象限（`scripts/ingest_batch2.py`），防跨中线裁伤
- 素材入 `assets/library/` + `assets.json` 登记；分镜只准引用已有素材，缺的进需求清单

## 工程与渲染

Remotion 模板在 `<sticker-repo>/remotion/`（1080×1440 @30fps）。新视频：拷贝模板 → 改 `timeline.js`（force_align 输出）+ `scenes/` + 音频 → 逐场景抽静帧检查 → 整片渲染：

```bash
REMOTION_ENTRY_POINT=./<slug>/index.jsx node scripts/remotion-cli.mjs render \
  ./<slug>/index.jsx <CompId> out/<name>_tmp.mp4 --codec=h264 --video-bitrate=<N>k --x264-preset=medium --concurrency=8
```

码率不用 crf（2026-09-14 起成片 <100MB）：`N = floor(95×8000 / 时长秒) − 192 − 140`；产物先 `_tmp`，ffprobe 读出时长再改名。

组件速查（`remotion/components/Stage.jsx`）：GridBackdrop 方格纸 / Sticker（弹入+sway+flip+name 名牌）/ SpeechBubble 对话气泡 / Fly 抛物线传递（visibleFrom/hideAfter）/ PriceTag 价签 / Note 便签 / Subtitle 字幕轨 / Disclaimer 免责水印。

## Bobby AI 露出（每条都要，但分平台）

规则来源：内部记录（对外产出必须带 Bobby AI）+ `bobby-ai-brand-messaging`（官方话术，**不许自造定位语**）+ `cn-platform-compliance-redline`（国内平台合规）。

### 前 30 秒必露一次（2026-09-10 起铁律，与落版并存）

抖音人均观看只有 30 秒左右，只在片尾落版等于多数人没看到。每条贴纸视频**前 30 秒内（理想 8~25 秒）**出现一次 Bobby AI **app icon + 官方字标**：脚本里对应一句工作痕迹句（「用 Bobby AI 把这几年的数据拉了一遍，有个挺有意思的发现」，≤20 字，不用「我查了」），画面在同一拍出 icon + 字标，停 2~3 秒退场。素材已在 `remotion/public/logos/`：`BobbyAI_icon.png`（独角兽 icon）+ `BobbyAI_light.png` / `BobbyAI_purple.png`（字标），禁手打文字。形式：Bobbie 手里的手机屏上亮出 icon+字标、或便签角落的来源署名、或角标 chip；不做产品卡/UI 演示。不占 frame 0，不与主数字同 y 区。分镜表单独标 `【Bobby前置位】`，交付前抽帧验收。片尾落版照旧。

### 国内平台（抖音 / 小红书）——只做品牌级露出

落版两行，别再加：

```
关注 Bobby AI                ← 34px，Bobby AI 用品牌紫
AI 让投资简单有趣              ← 29px 紫色（官方 slogan）
自然语言就能问 · 1000+ 数据源 · 越用越懂你   ← 23px，分隔线上方（10-08：24 小时盯盘暂不提，见 rules §0.5）
```

**能讲什么 vs 不能讲什么**（这条比"要不要露出"更重要，两边都别走极端）：

| 可以讲（信息/认知/交互类） | 不能讲（交易执行类＝展业特征） |
|---|---|
| 自然语言就能问，不用学术语 | 一句话生成投资组合 |
| 1000+ 数据源（行情/新闻/情绪） | 智能下单、条件单、平仓 |
| ~~24 小时盯盘~~（暂不提，产品还做不到） | 期权策略配置、抄底宝 |
| 越用越懂你的偏好 | 推荐具体标的、收益承诺、开户引导 |

**融入方式**：不要单独插一张产品卡，让 Bobby **回答画面此刻正在算的那个问题**。
范例（《钱越存越少》S7）：画面在把 0.95% 换算成六碗面，右侧同步出一张
`问 Bobby AI → "0.95% 一年到底是多少钱？" → "95 元 · 约 6 碗面"`，
下面就是 Bobbie 坐着吃那六碗。产品能力＝把数字翻译成人话，与内容严格同构，不违和也不展业。

**落版第三行**放能力三连：`自然语言就能问 · 1000+ 数据源 · 越用越懂你`（10-08 改，24 小时盯盘暂不提）。

**其余红线（踩了会被判非法展业，直接限流/封）**：

- **不做产品功能演示**：不放"一句话生成投资组合""智能下单""期权策略配置"这类对话卡、界面截图或操作演示。这是无牌照展业最典型的特征。（2026-07-30 踩过：给通胀那条加了张 Bobby 生成组合的对话卡，被用户当场叫停。）
- **不用官方定位语原句**：「首个金融交易领域的 AI agent」含"首个"，属广告法绝对化用语，小红书尤其敏感。国内落版只用品牌名 + slogan。
- 不出现推荐标的、收益承诺、引导买入/开户的表述；口播里的"让钱去干活""研究投资"这类泛表述可以，但不能落到具体动作。
- 免责水印 `内容仅供科普 · 不构成投资建议` 全片常驻（`Disclaimer` 组件，已默认挂在 Video.jsx）。
- **抖音合规关卡（焊死）**：分镜定稿前过 `平台合规自检清单（自备）` 的**画面红线**（不用真钞/撒钱画面——表现"钱"用贴纸和数字；金融危机题材不用跳楼梗；不出现赌场/筹码/彩票元素；不用点燃吸烟镜头；素材不带第三方水印）+ **话术黑名单**（口播/字幕里"翻身/回血/上岸/稳赚/保本/第一/首个"零命中）。成片交付前跑该 skill 的发布前整表。
- **TikTok 投放版（09-18 焊入）**：屏上不放胜率 / 平均收益 / 回测收益大字卡；历史统计出现那一拍同框 *Past performance is not indicative of future results* + 来源；片内一次"Bobby AI by RockFlow · AI 投研工具"身份行；不出群/课/订阅。midterm0917 因"胜率95.8% 平均+22.3%"卡被 TikTok SG 拒。
