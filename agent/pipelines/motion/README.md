# 口播音频 → Remotion 动效解说视频

把一条口播音频做成全屏 motion graphics 解说视频：观众听原声口播，画面用动效、emoji、logo、大数字帮助理解。成片案例：《Q2 财报周前瞻》3'08"（2026-07，工程 `earnings/`）、《谷歌Q2财报前瞻》3'44"（2026-07，工程 `googleq2/`，**新模板首选**：含高管抠图出场组件、字幕安全区、分层转场）。

> **2026-10-08 起先走 `video-agent`**：开工先出【制作单】定 格式（`video-agent/craft/formats.md`）× 皮肤（`skins.md`，新契约皮肤在 `./skins/`）× 字体配对（`motionkit/type.js`）。分镜表多两列「构图」「镜头·接缝」；写代码时可用 motionkit 新层 `Camera/Punch/Parallax`（镜头）、`Shot/LeakAt`（切点）、`Candles/SplitFlap`（金融组件）；Remotion API 细节查 `remotion-best-practices`（钉 4.0.437 版）；成片加跑 `pace_check.py` 节奏体检 + subagent 审片卡。

## 流程总览（六步，第 3 步是硬闸门）

1. **转写** — 带时间戳转写音频，通读全文
2. **写动效计划** — 视觉系统 + 逐段分镜表 + 待确认点
3. **⛔ 给用户过目，等确认后再写代码** — 用户没点头前不搭工程。用户当初明确要求"先通读内容、写计划、看过之后再执行"，这是本 skill 的合约
4. **搭 Remotion 工程** — 场景代码 + 时间轴对齐
5. **关键帧抽查** — 每个场景渲 1-3 帧静帧，肉眼过一遍再整片渲染
6. **整片渲染 + 交付** — MP4 拷回音频所在目录，汇报成片参数和分镜清单

## 每次执行硬要求（分镜 + 剪辑 + 交付 · 用户历次指令汇总，2026-09-17 焊入）

> 总清单在 `agent/rules/requirements.md`（§0 暗号默认值、§2 分镜、§3 剪辑渲染、§4 交付包），**接到音频先读 §0+§2，渲染前读 §3，交付前按 §4 出完整物料包**。下面是最常被打回的条目拷贝，冲突时以总清单为准。

- **暗号**：`去气口1.3` = degap + atempo 两步连做，只切气口每句完整，对齐一律对变速版；`纸质/白板/胶片(少粒子)/3D` 是皮肤指令；"多动效多图多视频多emoji少文字"是默认要求不用等用户说；`中英版` = 同场景换 timeline_en + 播音级英文 TTS。
- **闸门**：先出文字版分镜表等确认，不许直接渲；镜头不要分太碎、动效承上启下，每拍 ≥50 帧；AI 生图需求单独列清单提醒用户；Bobby 截图位先留空并附"该问 Bobby 什么"。
- **少文字多视效**：每拍 ≤1 关键词 + 1 数字，卡片一行，chip ≤8 字，字幕已说的不重复上屏；机制段写成推演动画不用文字卡；每拍至少一种视效（emoji/logo/真人抠图/实拍/图表/3D/2.5D），相邻场景不同构图；口播提到的人必须出真人抠图或实拍；实拍默认 2–3 处（投教纸面可到 5 处），台账记账不跨期复用，只用无水印源。
- **封面/首帧**：frame 0 完整（日期 + 真人 + 大标题 + 硬数字），`S00` 硬写 0；每条肉眼可辨不同并与 covers/ 存档比对；**封面人物 = 本片主角方，政策线先问用户"特朗普还是当事人"，不默认特朗普**；多主体题全员在场；元素不互压；frame 1 起强冲击动画且不用归零型手法；投研线实拍视频打底开场，投教纸面线用纸面封面 + 拍立得窗口实拍；封面给 2–3 字核心词。
- **Bobby 制作侧**：一律官方 logo 图禁手打；前 30 秒 icon + 字标一次（`【Bobby前置位】` 单独一行）；3–4 处分段功能位对应脚本，形式 = Bobby 回答画面此刻在算的问题，国内不做交易 UI 演示，小红书版不放任何截图；落版两行；免责水印全片每帧常驻。
- **剪辑 QC**：token 级切点 + 字级字幕；timeline 键 grep 对账；每个多拍场景每一拍都抽帧；overlap-check 0 重叠 0 越界；span 垂直 margin 加 inline-block；上屏数字按脚本原意核对（"26pp"≠"26%"）；改字时语音/字幕/动效三处同改；若用户要"上字幕"：单行无标点白色最下方零动效不挡动效。
- **渲染**：成片 **<100MB** 用硬码率公式 `floor(95×8000/秒) − 192 − 140` kbps + `--x264-preset=medium --concurrency=8`，不用 crf 不用 slow；胶片 grain 0.28 且颗粒用静态 PNG；产物先 `_tmp` 再 ffprobe 校验改名，不 pgrep，不覆盖源；3D 加 `--gl=angle`；QC 第一张必是 `--frame=0`，≤30 秒抽帧验 Bobby。
- **交付包（不等用户追问，发在对话不写 md）**：成片路径参数 + 发布标题(抖音 <20 字 / 小红书禁个股+涨跌词、禁"AI"字) + 视频常驻标题 + 封面标题与 2–3 字核心词与人物元素 + 视频简介 + 社群文案两框(框 2 带 5 条可复制提问) + 小红书版差异说明 + 中英双版各一份 + 尾注三行（合规结论 / 去 AI 味 / Bobby 前置位验收帧）。

## Step 1 转写

用本 skill 自带脚本（fsmn-vad 切段 + SenseVoice 逐段识别，依赖已装在系统 python3.11）：

```bash
python3 \
  agent/scripts/transcribe_ts.py <音频文件> <输出transcript.json>
```

输出每段 `{start, end, text}`。**注意**：去过气口的音频句间无停顿，VAD 会切出 60s+ 的长段——属正常，句级时间点用下一步的 `align_tokens.py`（token 级）解决——字符比例法已弃用于正片，见下文。

通读全文，把 ASR 错字按正确写法记下来（品牌名、术语、数字单位最容易错：Megapack→"map pack"、CapEx→"KPX"、FSD→"F4D"、18A→"十八安"之类），上屏文字一律用正确写法，数字以口播为准。

## Step 2 动效计划（交给用户看的文档）

先算好分镜切点。**用 `align_tokens.py`（token 级时间戳），不要用 `align_marks.py`**：

```bash
# 先转写一次并打印带时间的全文（挑锚点用）
python3 \
  agent/scripts/align_tokens.py <音频> --dump tokens.json

# 再定位各分镜切点（可反复跑，不重复转写）
python3 \
  agent/scripts/align_tokens.py tokens.json "开场句开头" "第二段开头" ...
```

输出秒数 + 30fps 帧号 + 匹配度。**每个锚点匹配度要 1.00**，低于 0.85 就换锚点。

- **锚点按 ASR 实际识别的错字写**（韩股→盘股、CapEx→kpex、DRAM→DRNM），才能精确命中；上屏文字才用正确写法
- `align_marks.py`（字符比例法）**已弃用于正片**：在去过气口的音频上实测最大偏差 **4.03s / 121 帧**，且漂移双向（前半段画面偏晚、后半段偏早），靠平移救不回来。只在临时估算时用
- 拿到帧号后**先算每拍时长**：`（下一拍帧号 − 本拍帧号）`。低于 50 帧（1.7s）的拍必须回头压缩场景内的 delay/dur，否则动效跑不完就被切掉（本条 S7 只有 40 帧，全部延迟从 62 压到 34）

### 事件复盘长片的叙事骨架（≥5 分钟的「谁干的」类选题，选用）

来源：小Lin说《韩股腰斩崩盘，背后的"推手"是…？》6'02"，24h 内 8.5 万赞 / 1 万收藏 / 5716 分享（拆解见 `<workspace>/复盘视频拆解_小Lin说韩股崩盘_20260821.md`）。

**什么时候套这个骨架**：口播稿讲的是一个已经发生的事件，且能回答"表面原因不是真原因，真凶是谁"。个股财报快评、前瞻、投教科普都不适用，别硬套。

| 进度 | 段落 | 这一段要交付什么 |
|---|---|---|
| 0:00–0:10 | 现场 | 一个砸脸的大数字 + 现场实拍。**不解释**，只呈现 |
| 0:10–0:40 | 极端反差 | 之前多风光 ↔ 现在多惨，两个数字对撞 |
| 0:40–1:00 | 抛凶手 → 全部否定 | 列 2–3 个观众脑子里已有的解释，逐个否掉 → **悬念①** |
| 1:00–2:40 | 故意走错路 | 讲一个"看起来完全正确"的答案，讲扎实（时间线打点 / 对照曲线 / 数据）。观众此时以为片子要结束了 |
| **≈2:40（44%）** | **自己推翻自己** | 「这解释了 X，解释不了 Y」→ **悬念②**。这一拍就是本 skill 已有的**第二钩子**，位置正好落在 45%–60% 区间 |
| 2:50–3:20 | 真凶登场 | 点名，给它的时间线（什么时候出现的，和崩盘差几天） |
| 3:20–4:40 | 机制讲成人话 | 用一个**具名的**比喻把机制拆开（原片用"小丽奶茶店"，有名字、有金额、有画面。不要用"某公司 A"） |
| 4:40–5:00 | 【产品位】 | Bobby AI 在这里出现——观众刚被机制绕住、正想自己查一下的那一秒，不是硬插 |
| 5:00–5:50 | 后果 + 一个梗 | 抗议 / 问责 / 政策收紧；硬内容里每 90 秒插一个笑点 |
| 5:50–6:00 | 反讽金句 | 一句话把整件事的荒诞钉住 |

**和已有两道闸的关系**（不冲突，但要分清）：
- **25 秒结算线**交付的是"**这事有多惨、多反常**"（大数字 + 反差），**不是**"为什么"。答案必须留到 2:50 之后。前 25 秒把凶手说了，这个骨架就废了
- **第二钩子**就是上表 44% 处的「自己推翻自己」那一拍，分镜表里按原规则单独标出

**核心机制是悬念给两次**：0:40 否定显而易见的答案挂住一次，然后花 100 秒讲一个扎实但不完整的答案，2:40 亲手推翻它再挂住一次。这是撑住 5 分钟以上片长的唯一装置。**结论先行 + 理由①②③ 的说明文结构在这类选题上留不住人**——观众第 20 秒拿到答案，后面没有继续看的理由。

**合规**（平台合规自检清单 优先级高于本骨架）：原片用了跳楼实拍和"送进绞肉机"，这两类**不可照搬**。等效替代：抗议人群 / 摆花圈 / 国会与政府发布会 / 交易大厅 / 乌云压顶的证券大楼；反讽保留、暴力与自杀意象去掉。讲"金融产品害人"时靶子打在**产品机制**（杠杆、庞氏、假平台、保本承诺）上，不要滑到跟单/带单。

计划文档结构（markdown 发在对话里）：
1. **视觉系统** — 引用品牌规范（见 design-system.md 的速查区），说明底色/强调色/涨跌色/公司出场规范/文字纪律/转场
2. **分镜表** — 每行：编号 | 时间区间 | 口播内容概括 | 画面与动效描述 | **素材**（动效/实拍·画中画/实拍·背景/图表，实拍标来源如 `pexels:12345`）。分镜按口播语义切段，一个场景讲一件事。**S0 开场必须单独写"封面帧设计"**：日期怎么放、用谁的抠图照片、和上一条视频的首帧差异点是什么（见 design-system.md 首帧规范）。**实拍/图片每期 2–3 处**（画中画/背景/图片各算一处），选段映射与获取命令见 broll-assets.md；候选素材用 agent/scripts/broll_fetch.py 搜好写进计划，给用户看时附素材预览链接；实拍素材入片前先 `broll_fetch.py qc` 抽帧看图质检。**节奏两道闸（2026-07 双平台实测）**：① **25 秒结算线**——抖音人均观看只有 20~27s 且与片长无关，核心增量（时间表/最大看点/反差结论）必须在前 25 秒内视觉交付完；前 2 秒不许被品牌片头或纯入场动画占用，第一拍就要见到标的+硬数字（2s 跳出的分水岭）。② **第二钩子**——3 分钟以上的片子在 45%~60% 进度处安排一段反差数字大字卡/数据密集段（实测跳过率峰值全在该区间、回看率峰值全在数据密集点），分镜表里单独标出这一拍。③ **Bobby AI 前置位（2026-09-10 起铁律）**——前 30 秒内（理想 8~25 秒）画面必须出现一次 Bobby AI **app icon + 官方字标**，触发点＝口播说到「用 Bobby AI …」那一拍同步入场，停 2~3 秒退场；形式轻（角标 chip / 数据卡的来源署名角 / 小画中画），不是全屏产品卡、不做 UI 演示；不占 frame 0 封面拍。分镜表单独写一行 `【Bobby前置位】`标时间点；口播里没这句时也要在前 30 秒的第一张数据卡上挂来源署名。素材与组件见 design-system §1.6。片尾落版照旧不取消
3. **分镜多样性规则**（防抖音同质化，服务"每期 ≥60% 画面不同"）：
   - **逐句归属**：每句口播都有明确画面归属，一个视觉单元 2–6 秒；超过 8 秒的场景必须内部分拍（换构图或换元素）
   - **画面类型轮换**：类型 ∈ {动效卡, 图表动画(折线/仪表盘/象形阵列), 实拍 B-roll, 2.5D 运镜图(broll_fetch animate), 图标线稿(DrawSVG), 3D动效(Globe3D 地球/Bars3D 柱阵，见 three-motion.md)}，**相邻场景不用同一构图模式**；实拍/图片总量仍守 2–3 处配额；3D 场景每期最多 1–2 个
   - **B-roll 搜索词**：每个实拍镜头写 3 个候选英文搜索词（1–3 词、具象名词、带主体词，如 federal reserve building / trading floor / cash counting），按叙事顺序排进分镜表——抽象概念必须翻成具象画面（"放水"→cash printing，"情绪"→trading screens red）
   - **每期视觉变量**：DotGridBackdrop 的 seed/gap、enter preset 组合、图标集、实拍素材，至少换两样（组件见 remotion-workflow.md motionkit 节）
3. **执行方案** — 工程位置、素材来源、渲染产出路径
4. **待确认点** — 至少要问清：**画面比例**（2026-08-11 起默认 **1085:885 宽高比，实现为 1084×884 偶数画布**，用户未另说就用它；改比例=每个场景重排，务必先定）；字幕（默认不上整句字幕，只有画面关键词；**2026-08-11 起默认不留字幕安全区**——用户字幕在画面外，贴底元素 bottom ≥ 40 即可）；口播里提到高管/名人时，问是否要真人抠图出场（用户很吃这个）；成片预计超过 3 分钟时，问是否同时出一版 **60-100 秒抖音精华版**（实测 60-100s 是完播率最优长度带，播放占比 25% vs 5min+ 条的 8%；5min+ 完整版只投小红书——那边人均观看时长是抖音 2 倍）

发出计划后**停下**，等用户回复。用户指定改哪个分镜就改哪个。

## Step 3-4 工程与场景

读 `remotion-workflow.md`（工程位置、从模板起新视频、组件清单、渲染命令）。写场景代码前读 `design-system.md`（品牌 tokens、动效语言、布局护栏、踩过的坑）。

核心约束（详见参考文档，这里是不能破的底线）：
- **免责水印全片常驻**：在 `Video.jsx`（或 Root 组件）顶层挂一个 `<Disclaimer />` 组件，position: absolute、全片每帧可见、opacity 0.35-0.4、右上角或左下角。文案按内容适配——科普/投教类用「内容仅供科普 · 不构成投资建议」；公司介绍/商业拆解用「内容仅供信息参考 · 不构成投资建议」；财报解读用「内容仅供信息参考 · 不构成投资建议」；历史/事件类用「内容仅供科普 · 不构成投资建议」。**不是只放在片尾——是每一帧都在。**
- **抖音合规关卡（焊死）**：分镜计划发给用户前，先过 `平台合规自检清单（自备）` 的**画面红线**（不用真钞/撒钱画面、金融危机不用跳楼梗、无赌场/筹码/彩票元素、无点燃吸烟镜头、素材无第三方水印）+ **话术黑名单**（屏上关键词和字幕里"翻身/回血/上岸/稳赚/保本/第一/首个"零命中）。成片交付前跑该 skill 的发布前整表，汇报里附一行合规结论。
- **TikTok 投放版（09-18 焊入）**：屏上不放胜率 / 平均收益 / 回测收益大字卡；历史统计出现那一拍同框 *Past performance is not indicative of future results* + 来源；片内一次"Bobby AI by RockFlow · AI 投研工具"身份行；不出群/课/订阅。midterm0917 因"胜率95.8% 平均+22.3%"卡被 TikTok SG 拒。
- 每帧独立可计算：动画只依赖 `useCurrentFrame()` + interpolate/spring，不用 state/随机数（Remotion 并行乱序渲帧）
- 屏上只出现**关键词、数字、emoji、logo**，绝不整句上屏
- **Bobby 前置位验收**：交付前抽 ≤30s 区间的帧，确认 app icon + 字标已出现过一次（`--frame=` 抽帧存 `out/stills/<slug>_bobby.png`）；没出现不交付
- 时间轴帧号全部来自 transcript 对齐结果，写进 `timeline.js` 统一管理，场景内只引用常量

## Step 5 关键帧抽查

每个场景挑 1-3 个信息最满的帧渲静帧，用 Read 当图片看：

```bash
REMOTION_ENTRY_POINT=./<slug>/index.jsx node scripts/remotion-cli.mjs still \
  ./<slug>/index.jsx <CompId> out/stills/f<N>.png --frame=<N>
```

工程含 3D 场景（motionkit/three）时，still 和 render 命令都要加 `--gl=angle`，否则 WebGL 黑屏。

逐帧检查清单：文字溢出/换行、元素相互重叠（尤其顶部章节标签 vs 场景标题）、上一拍残影没退干净、emoji 是否自带违和底色块（方块底箭头类 emoji 一律换 SVG/无底色符号）、连线是否对准目标。发现问题改完**重渲同一帧**确认，再进入整片渲染。

**frame 0 必抽**：渲 `--frame=0` 静帧，核对三件事——日期在、抠图主视觉完整可见、和历史成片封面（`out/stills/covers/` 存档）肉眼可辨地不同。通过后把这帧拷进 `out/stills/covers/<slug>_f0.png` 存档，供下条视频比对。

## Step 6 渲染与交付

```bash
REMOTION_ENTRY_POINT=./<slug>/index.jsx node scripts/remotion-cli.mjs render \
  ./<slug>/index.jsx <CompId> "out/<成片名>_tmp.mp4" --codec=h264 --video-bitrate=<N>k --x264-preset=medium --concurrency=8
```

**码率不用 crf（2026-09-14 起成片必须 <100MB）**：`N = floor(95×8000 / 时长秒) − 192 − 140`（例 374s→1700，542s→1070，90s→8100）；胶片皮肤 grain 0.28。产物先落 `_tmp`，`ffprobe -show_entries format=duration` 读出时长再改正式名，不用 `pgrep` 判完成，校验前不覆盖源文件。

整片渲染放后台跑（约 10-20 分钟）。完成后：`ffprobe` 验证时长/分辨率/音轨都在 → 从成片抽 2 帧确认封装无误 → 拷贝到音频所在目录 → 汇报：成片路径、参数（分辨率/fps/时长/大小）、分镜清单、哪里可以微调。

## 设计铁律速查（完整版在 design-system.md）

- **首帧防同质化（抖音判定，最高优先级）**：第 0 帧就是封面，必须是一张排版完整的独特封面——① 含**当天日期**元素；② 主视觉用**照片抠图**（高管/名人/产品 rembg 抠图），不能是纯底色+文字（黑底点阵同样算纯底）；③ 构图/点缀每条视频都换，和历史成片首帧肉眼可辨地不同。开场元素在 frame 0 必须已完整可见（不能全靠 spring 从 0 弹入——那样首帧就是空紫底，条条一样）。背景：2026-07-22《谷歌Q2》被抖音判"批量发布同质化内容"限流，根因就是首帧全是同款空紫底
- **实拍点缀防同质化（抖音判定，次高优先级）**：每期掺 **2–3 处**实拍/图片素材（品牌卡片画中画 / 压暗做背景层 / Ken Burns 图片），动效仍是主体；素材从 broll-pool 台账取，**已用过的素材不跨期原样复用**；成片后 `broll_fetch.py used` 记账。完整规范见 broll-assets.md
- **黑底 + 点阵**（2026-08-10 起弃紫底）：背景一律 `motionkit/DotGridBackdrop`（近黑 #050505 + 点阵 + 漂移光晕，每期换 seed/gap）；紫色降为元素色，涟漪只用于大章节转场和收尾；品牌黄 `#F9F339` **只给全片最关键的一两处信息**
- 涨=绿 `#2ebd85`，跌=红 `#f6465d`，固定不换
- 公司出场 = 官方 logo 圆角块 + `$TICKER` 药丸（logo 从 `assets.parqet.com/logos/symbol/<TICKER>?format=png&size=200` 拉，存 public/logos/）
- 数字一律 count-up 滚动
- **转场分层级**：只有大章节切换用涟漪擦除（前后各 10 帧 ≈0.67s），小节切换一律硬切——全片涟漪 ≤10 次，否则转场吃掉太多时间
- **字幕安全区（2026-08-11 起默认关闭）**：字幕在画面外，贴底元素 bottom ≥ 40；仅当用户明确要"字幕压视频底部"才恢复 ~150px 预留
- **文字再少一点**：卡片只留一行主文案（副标题默认不加），chip ≤10 个字；用户反馈过"字还是有点多"
- **入场过冲 ≤1.3**：Pop from>1.3 的过冲会让卡片入场瞬间放大出框；只有局部小元素（单个数字/图章）可用到 1.3
- 中文 PingFang 最粗只有 600，大数字用 `-apple-system` 800 补
- **平台分发**：成片节奏按"25 秒结算线 + 中段第二钩子"验收；时长/平台适配、发布时机、封面标题分平台规则见 `agent/script/references/platform-douyin-xhs.md`（2026-07 双平台实测手册）
