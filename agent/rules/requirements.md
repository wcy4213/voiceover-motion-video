# rules/requirements.md（公开版占位）

内部版本是 2026-07 至 2026-10 每一次真实打回与指令的逐条清单（§0 暗号与默认值 / §0.5 规则冲突口径 / §1 脚本 / §2 分镜 / §3 剪辑渲染 / §4 交付包 / §5 维护），绑定了具体品牌、产品事实和平台判罚记录，**不随仓库分发**。

公开可复用的部分已经沉淀到：
- 画面与首帧规范、踩坑清单 → `../pipelines/motion/design-system.md`
- 审美与动效数值、审片卡 → `../craft/art-direction.md`
- 留存设计与节奏门槛 → `../craft/retention.md`
- 格式库 / 皮肤库 / 字体许可 → `../craft/formats.md` · `../craft/skins.md` · `../craft/fonts-license.md`
- 决策引擎（内容 → 形式 → 手法）→ `../decide.md`

自建时照这个骨架起一份自己的 `requirements.md`：每条规则写清**首次出处日期**和**可打勾的动作**，新指令先进这里再同步到各模块；与平台合规清单冲突时以日期更新的为准。
