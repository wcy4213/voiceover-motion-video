# 留存手册（钩子 · 开环 · 再钩 · 节拍图 · 节奏基线）

> 北极星：**注册/转化**，曝光与完播是过程指标（memory content-growth-rules / video-registration-conversion-baseline）。留存是让 Bobby 前置位和功能位真的被看到的前提——抖音人均只看 20–27 秒。
> 本文三层：§1 自家实测（最高优先级）→ §2 机制与规则 → §3 节拍图模板 → §4 节奏基线与 pace_check 门槛。外部证据见 §5。

## §1 · 自家实测（2026-07 双平台，已写进老规则，这里汇总）

| 现象 | 数字 | 对应动作 |
|---|---|---|
| 抖音人均观看 | 20–27s，与片长无关 | 25 秒结算线：核心增量前 25 秒交付完 |
| 2 秒跳出是分水岭 | 投教贴纸片 2s 跳出 62.8% | 第一拍就见标的 + 硬数字；前 2 秒不许被片头/纯入场动画占 |
| 3 分钟以上片子跳过率峰值 | 45–60% 进度 | 第二钩子：反差数字大字卡 / 数据密集段 |
| 回看率峰值 | 全在数据密集点 | 数据拍要"值得暂停"——一屏一个大数 + 一个对比 |
| 最优完播长度带 | 60–100s（播放占比 25% vs 5min+ 的 8%） | 抖音出 60–100s 精华版，5min 完整版投小红书 |
| 结尾提问 | 只有 4–6% 的人听到 | 互动提问放前 30 秒 + 置顶评论承接 |
| "什么是 X"冷开场 | 小红书封面 CTR 5.2%（账号财报条一半） | 热点入题；标题冲突悬念式 |

## §2 · 机制（为什么人会留下来）

### 2.1 钩子类型（第一句 = 主角 + 结论 + 硬数字，下面是"结论"部分的写法）

| 类型 | 句式骨架 | 适合格式 |
|---|---|---|
| 反差数字 | "超预期 5 项，盘后还跌 8%" | scorecard / breaking |
| 半揭晓 | "第一名一年涨了 11 倍——但它不是你想的那家" | countdown |
| 反常识 | "高股息股票，最容易让人亏钱" | myth-fact |
| 损失/代价 | "这笔钱放活期，一年少赚一碗面钱 × 365" | one-number / what-if |
| 悬案 | "跌了 40%，所有人都在骂错了人" | case-file |
| 时间压力 | "周三之前，盯住这一个数" | breaking / timeline |

禁：冷概念开场、"今天给大家讲讲"、先自我介绍、先品牌片头。

**三层钩子同时开火**：口播第一句 + 屏上 3–7 个**和口播不同**的字（不是复读）+ 开场画面（实拍/真人/硬数字），0 秒同时到位。**给出数字，扣住为什么**：开头亮结论和数字，机制（为什么）留到 ~25 秒交付——好奇心在"知道一半"时最强（Kang 2009 / Gruber 2014）。

### 2.2 开环（open loop）——撑住中段的唯一装置

- **开环 = 提前承诺一个答案，延后兑现**。每个开环必须在分镜表里写明"在哪埋 / 在哪兑现"。
- 60–100s 片：开头 1 个大开环（兑现在 60–80%）+ 中段 1 个小开环。
- 5min 片：开头大开环 + 每 60–90 秒一个小开环（链式：兑现一个的同时埋下一个）+ 44–60% 处"自己推翻自己"的第二钩子。
- 开环一定要**兑现**，而且要**明说**"答案来了"——开环起作用靠的是好奇心，不是"没完成的事记得更牢"（蔡格尼克效应 2025 年 59 项研究元分析未复现）。不兑现等于骗点击，评论区会反噬。

### 2.3 再钩（re-hook）节奏

**刺激时钟（12 点钟法，影视飓风 HKRR 体系；与 25 秒线的关系见 rules §0.5）**：大刺激落在全片 **0 / 25 / 50 / 75%**，中间放小刺激。90 秒片 ≈ 0 / 22 / 45 / 67 秒——0 与 25% 对应老规则的开场 + 25 秒结算线，50% 对应第二钩子，**新增 75% 一拍**（真凶揭晓 / 榜首揭晓 / 最大反差）。3 分钟以上把 50% 那拍提前到 ~45%，赶在实测跳过峰值之前。每个大刺激都要**比上一个更强**（阶梯式），开场数字不是全片最大的数——留一个更大或更反常的数给 45–60% 那拍。

- 口播：每 20–30 秒一句"再钩句"——"但这还不是最离谱的""接下来这个数字才是关键"。⚠️ 和"段落式连续口播、禁碎片化"不冲突：再钩句是段内的胶水句，不是独立短句炸点。
- 画面：每 2–4 秒一个新视觉事件（开场 1–2 秒一个）；每 8 秒以内换一次构图或镜头运动；大章节换底（art-direction §4）。
- **别快过头**：50 条高表现知识类 TikTok 平均 2.7 秒一个切（16–84 分位 1.9–5.3 秒）；242 人实验里节奏更快反而**降低**自评完播和回看（Dost & Huang 2026，会议论文、便利样本）。所以"1–2 秒一个事件"只给开场拍，正片 2–4 秒；pace_check 正片段每 10 秒 >12 个事件要回头看是不是在炫技。
- 段落之间用"但是 / 所以"推进，不用"然后"（Jenny Hoyos）；每个抽象数字配一个日常换算（"7 万亿 = 每个美国人 2 万美元"）。
- **模式打断**（pattern interrupt）：每 30–45 秒一次"画面语法突变"——从图表切到实拍、从平面切到 3D、从满屏切到留白大字。全片 3–6 次。

### 2.4 屏幕文字 vs 口播

- 屏上只给锚点（关键词 + 数字），不重复口播整句（老规则）。
- 但**静音观看**的人（信息流里相当一部分）只能靠画面理解——每一拍的骨架测试要过：遮字也看得懂在讲什么（art-direction §4）。
- 字幕在画面外（用户自加），画面内不留字幕安全区（默认）。⚖️ 证据很硬：字幕显著提升理解与看完意愿（Gernsbacher 2015 综述 100+ 研究；Verizon 2019 n=5616，80% 说有字幕更可能看完）——**"画面少字"≠"没有字幕"**：发布时必须有字幕轨（用户在剪映加，或平台自动字幕），关键词卡和字幕轨是两层。

### 2.5 结尾

- 不要"感谢观看"式拖尾；最后 3 秒 = 一句判断 + 落版（落版本身 ≤ 2s 动画 + 静止）。
- 可以做**回环**：最后一句接回开头的画面/问题，让自动重播的人无缝看第二遍。YouTube Shorts 自 2025-03-31 起每次重播都计一次播放；TikTok 对看完长视频权重很高；抖音公开的目标含完播/评论/点赞/分享/长期消费。⚖️ **TikTok / Shorts 版落版 ≤1.5 秒**，或让落版最后一帧接回 frame 0；国内版落版两行照旧。
- 只留**一个**行动号召；Bobby 功能位算内容，不算 CTA。

### 2.6 互动设计（评论 / 转发 / 收藏怎么来的，10-08 抖音 585 条调研）

节奏快慢解释不了互动（27 条样本里基本不相关），互动是**设计**出来的。每条片子在制作单里选 1–2 个：

| 机制 | 做法 | 拉动 |
|---|---|---|
| 人人能答的问题 | 标题/片尾是一个感受或经历问题（"你那边涨了吗"），不是知识题 | 评论 |
| 地域/身份点名 | 口播点几个地区或人群，评论区自动接龙"东北呢" | 评论 |
| 收藏型清单 | 3–5 条可复用的东西（问法、指标、日期），口播一句"存一下" | 收藏 |
| 屏上打出"该问的那句话" | 代替"评论区领取"（导流红线）——观众截图/收藏 | 收藏 |
| 系列编号 | EP01 / 第 N 期 / 半月榜，固定格式 | 关注、追更 |
| 故意留一个槽点 | 一个无伤大雅、可以玩梗的细节（不能是事实错误、不能碰合规） | 评论 |
| 榜单留遗漏邀请 | "漏了哪个，评论区补" | 评论 |
| 制作参数片尾卡 | "数据由 Bobby AI 整理 · 用时 XX 秒" | 品牌记忆、"求同款" |
| **结尾指向一个具体的人** | 最后一句是"对某个人做一件事"（给 TA 发条消息 / @那个人约一下）| 转发（vibe知识大赏样本转/赞 0.4–1.5，是评论的 20 倍）|
| 结尾清单/公式 | ✓✓✓ 三件小事、一条公式、"下次有人……记得问一句" | 收藏（藏/赞 .26–.61）|

**禁用**：讨花讨礼物、"点赞到 XX 更新"、"评论区领取/私信领取"（诱导互动 + 导流红线）；性别对立情绪；撒钱画面。

## §3 · 节拍图模板（写进分镜表前先填这张）

```
时间   | 口播节拍            | 视觉事件（每 2–4s 一个）     | 留存装置
0–2s   | 主角+结论+数字      | 封面完整 → f1 起 punch-in    | 钩子类型：____
2–8s   | 第一个证据          | 实拍/数字砸入/人物出场       | 埋开环①：____
8–25s  | Bobby 前置位 + 核心增量 | BobbyCallout + 主图形      | 25 秒交付：____
25–45s | 展开                | 换构图 + 镜头运动            | 再钩句
45–60% | 第二钩子（长片）    | 反差大字卡 / 模式打断        | 自己推翻自己
~75%   | 兑现开环①（最大反差）| 记忆点镜头                   | 大刺激④；长片埋开环②
末 5s  | 一句判断 + 免责     | 落版 ≤2s                     | 回环到开头？
```

## §4 · 节奏基线（pace_check 实测，2026-10-08）

| 成片 | 皮肤 | 时长 | 事件/10s | 最长空窗 | 前 10s 事件 | 静止段占比 |
|---|---|---|---|---|---|---|
| CPI议息 | 纪录片胶片 | 374s | 9.9 | 5.0s | 14 | 0% |
| 预测市场加息 | 纪录片胶片 | 319s | 8.0 | 10.6s | 11 | 0% |
| 标普纳入 | 白板 | 291s | 5.9 | 7.5s | 13 | 4% |
| Oura 上市 | 俯拍拆解台 | 306s | 4.9 | 12.2s | 12 | 23% |
| 四巫日 | 线索板蓝图 | 303s | 4.7 | 11.0s | 6 | 24% |
| 中期选举 | 线索板 | 412s | 4.7 | 9.8s | 2 | 23% |
| BE 燃料电池 | 黑底点阵竖版 | 306s | 4.0 | 16.5s | 3 | 44% |

⚠️ pace_check 对**持续运镜**的片子（AI 实拍、一镜到底）会少算事件——这类镜头看"画面是否一直在动"，不只看事件数。

**门槛（交付前）**：前 10 秒 ≥ 5 个事件；静止段占比 < 10%；最长空窗 < 6s；不存在整 5 秒无事件窗口（落版除外）。
**下一步（要用户配合）**：把这几条的抖音/小红书后台完播曲线和 pace_check 的事件密度对一下，验证"事件密度 ↔ 留存"在本账号是否成立；成立就把门槛写死，不成立就调阈值。后台数据管线

## §5 · 外部证据

与 §1 自家实测冲突时以 §1 为准。标 [未证实] 的是创作者经验，没有数据出处。

| 结论 | 出处 | 落到哪 |
|---|---|---|
| 前 3 秒亮出命题、6 秒内钩住 | TikTok Ads Help 创意最佳实践（2025-06，官方） | 第一句规则 |
| 广告 50% 效果在前 2 秒、90% 记忆在前 6 秒 | TikTok Marketing Science（2023，广告口径） | 2 秒分水岭 |
| 真人出镜 +9% 观看时长、故事结构 +16% | TikTok 委托研究（2023） | 真人首帧铁律 |
| 好奇心在"知道一半"时最强，且提升附带记忆 | Kang 2009；Gruber 2014 | 给数字、扣住为什么 |
| 蔡格尼克效应（没完成的更记得住）不成立 | Ghibellini & Meier 2025，59 项元分析 | 开环要明说兑现 |
| 知识类短视频平均 2.7s/切；更快反降完播 | Dost & Huang 2026（会议论文） | 正片 2–4s/事件 |
| 关键词浓缩上屏优于逐字上屏 | Adesope & Nesbit 2012 冗余效应元分析 | 每拍 ≤1 关键词 + 1 数字 |
| 字幕提升理解与看完意愿 | Gernsbacher 2015；Verizon/Publicis 2019 | 发布必须有字幕轨 |
| YouTube"开头"指标 = 30 秒时仍在看的比例，反映开头是否兑现封面/标题 | YouTube Help | 前 30s 兑现封面承诺 |
| YouTube 缩略图 A/B 按观看时长份额选，不按 CTR | YouTube Help | 封面别过度承诺 |
| Shorts 重播计播放（2025-03-31 起）；Shorts 最长 3 分钟（2024-10-15 起） | YouTube | 回环、落版 ≤1.5s |
| 3 分钟以上 YouTube 加章节：00:00 起、≥3 章、每章 ≥10s | YouTube Help | YT 横版简介 |
| 品牌片头/logo 放 0–3 秒是早期流失最常见原因 | 创作者共识 [未证实] | Bobby 前置位 ≥5s（老规则 8–25s 不变） |

**完播曲线诊断**（有后台曲线时用）：
```bash
python3 agent/scripts/retention_curve.py curve.csv --duration <秒> \
  --transcript transcript.json --pace pace.json
```
把流失分三类：**开场漏**（改第一句和 frame 0）/ **断崖**（看那一刻在说什么、画面是不是空窗）/ **匀速**（删中段，不重写）。断崖和 pace_check 静止段重叠 = 画面空窗导致流失的直接证据。思路来自 Jakeschincariol/youtube-agent-skill（MIT），已改写成本管线格式。

**没拿的**（许可或质量问题）：Jamailar/high-retention-video-script（影视飓风 HKRR，CC BY-NC，只借了刺激时钟的思路）；mrbeast-skill / claude-youtube / iart 里无出处的百分比数据；英文正则的钩子打分器（误判中文，还奖励"但是等等"这类套话）。
