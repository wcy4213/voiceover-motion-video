# 格式库 23 种（结构 × 节拍 × 视觉语法 × 留存装置）

> **格式 ≠ 皮肤**。格式决定"这条片子怎么讲、画面按什么语法组织"；皮肤决定质感。以前几乎所有片子都是同一种格式（结论先行的口播 + 逐段配卡片），只换皮肤——观众在第 3 条就认出套路了。
> 用法：制作单里选一个 id；脚本按"节拍"写（finance-video-script 负责句子本身），分镜按"视觉语法"出画面，"留存装置"写进分镜表对应那一拍。
> 时间按抖音精华版（60–100s）给；长版（小红书 5min）同比例放大，并在 45–60% 处加第二钩子（老规则）。

所有格式共用的硬规则（不重复写）：第一句 = 主角 + 结论 + 硬数字；大刺激落在 0 / 25 / 50 / 75%（retention.md §2.3，阶梯式一次比一次强，开场数字不是全片最大的）；前 25 秒交付核心增量；Bobby 前置位 8–25s；3–4 处 Bobby 功能位；免责中段一次 + 片尾一次；frame 0 完整封面。

## F01 `breaking` · 突发快评

| 节拍 | 时间 | 内容 |
|---|---|---|
| 现场 | 0–3s | 主角实拍/抠图 + 砸脸硬数字（"一夜跌 23%"） |
| 三件事 | 3–25s | 发生了什么 / 为什么 / 影响谁，每件一个画面主角 |
| 反差 | 25–45s | 市场的第一反应 vs 数据里的另一面 |
| 观察点 | 45–75s | 接下来盯哪两个数（带日期） |
| 收 | 75–90s | 一句判断 + 免责 + 落版 |

- **视觉语法**：时间戳 + 实拍 + 大数字；数字走 SplitFlap/乱码锁定；每件事一个独立构图
- **留存装置**：开场就承诺"第三件事才是重点"（开环），第三件事放 18–25s 兑现
- **皮肤**：terminal（首选）/ 黑底点阵 / glass（科技公司）
- **题材**：财报暴雷、政策突发、个股异动、宏观数据公布

## F02 `case-file` · 悬案复盘（谁干的）

已有骨架见 `pipelines/motion/README.md`「事件复盘长片的叙事骨架」（小Lin 韩股拆解），这里只补画面：
- **视觉语法**：嫌疑人卡片（3 张）逐个盖"排除"章 → 时间线打点 → 真凶卡片翻面 → 机制推演动画 → 后果蒙太奇
- **留存装置**：悬念给两次（0:40 否定显而易见的答案 / 44% 处自己推翻自己）
- **皮肤**：线索板 / 纪录片胶片 / terminal（数据型真凶）
- **题材**：崩盘、闪崩、熔断、资金出逃、监管突袭

## F03 `countdown` · 倒数榜单 Top N

| 节拍 | 时间 | 内容 |
|---|---|---|
| 预告 #1 | 0–4s | 直接把 #1 的**结果**亮出来但遮住名字（"第一名一年涨了 11 倍"） |
| #N → #2 | 4–60s | 每名 8–12s：logo + 一个数 + 一句为什么；名次越靠前越长 |
| #1 揭晓 | 60–80s | 揭名 + 最大的反差 |
| 收 | 80–90s | 共同规律一句 + 落版 |

- **视觉语法**：名次大号数字（每名换一个入场方向）、榜单条从下往上堆叠、上一名缩小留在侧边成"已揭晓栏"
- **留存装置**：#1 开头半揭晓（开环）；每 3 名插一句"前面这几个加起来都没第一名多"（再钩）
- **皮肤**：brutal / swiss / terminal
- **题材**：年度涨幅榜、机构持仓榜、ETF 规模榜、"最贵的 N 次错误"
- ⚠️ 合规：不是"推荐榜"；口径写成"数据里涨得最多的"，不出"值得买"

## F04 `myth-fact` · 误区 vs 真相

| 节拍 | 时间 | 内容 |
|---|---|---|
| 钩子 | 0–4s | 最反直觉的那条误区的结论（"高股息股票，其实最容易让你亏钱？"）+ 硬数字 |
| 误区 ×3 | 4–75s | 每条：「你以为」画面 → 硬切 →「实际上」画面 + 数据 |
| 收 | 75–90s | 一句方法论 + Bobby 能帮你查哪个数 |

- **视觉语法**：每条误区用**同一个画面翻转**（同一构图，左/前 = 以为，右/后 = 实际），硬币翻面 / 卡片撕开 / 画面"反色"
- **留存装置**：每条误区结尾抛下一条的标题（链式开环）
- **皮肤**：brutal / swiss / 手账
- **题材**：投教常识（定投、股息、杠杆 ETF、止损）

## F05 `versus` · 对决

| 节拍 | 时间 | 内容 |
|---|---|---|
| 擂台 | 0–4s | A vs B 两个 logo 对撞 + 一个让人意外的比分 |
| 回合 ×3 | 4–70s | 每回合一个维度（增速 / 利润 / 估值…），记分牌更新 |
| 裁决 | 70–90s | 不是"谁更好"，是"各自赌的是什么" |

- **视觉语法**：左右分屏 → 每回合一方"推"占画面面积（输的一方被挤小），顶部记分牌；最后合屏
- **留存装置**：比分在第 2 回合逆转
- **皮肤**：terminal / glass / swiss
- **题材**：英伟达 vs AMD、苹果 vs 微软、美债 vs 美股、黄金 vs BTC
- ⚠️ 合规：不下"买 A 不买 B"结论

## F06 `one-number` · 一个数字讲透

| 节拍 | 时间 | 内容 |
|---|---|---|
| 数字 | 0–3s | 满屏一个数（"7.21 万亿"） |
| 拆 | 3–50s | 这个数由哪几块组成（数字被"切开"成块，每块一个来源） |
| 比 | 50–75s | 和一个日常尺度对比（够买 N 个苹果公司 / 每个美国人 X 美元） |
| 收 | 75–90s | 它接下来往哪走，看什么信号 |

- **视觉语法**：同一个数字全片在场（缩小到角落继续存在），拆分用面积块/华夫格；比例尺对比
- **留存装置**：开头不解释这个数是什么（"这个数字今年多了 1 万亿，钱从哪来的"）
- **皮肤**：swiss（首选）/ terminal / glass
- **题材**：货基规模、国债规模、回购总额、资本开支

## F07 `timeline` · 时间线 / 历史重演

- **节拍**：今天的事件（0–4s）→ "上一次发生是在 X 年"（4–10s）→ 时间线回放 3–4 个历史节点（10–70s）→ 回到今天，对比差异（70–90s）
- **视觉语法**：横向时间轴持续向左推进（向量律：全片一个方向），年份大字邮戳式盖下；历史节点用老照片/胶片质感，现在用实拍
- **留存装置**："每一次之后 6 个月发生了什么"，最后一次的结果留到最后
- **皮肤**：纪录片胶片 / 手账 / 东方大楷宣纸（候选）
- **题材**：降息周期、熔断史、四巫日、历次 IPO 潮

## F08 `what-if` · 情景推演 / 模拟

- **节拍**：设定（"如果你 2020 年放了 1 万美元在…"，0–5s）→ 三条路径同时出发（5–20s）→ 关键时点分叉（20–70s）→ 终值对比 + 一个反直觉结论（70–90s）
- **视觉语法**：三条彩线/三个小人同时跑，分叉点停帧标注；终点并排柱
- **留存装置**：一开始让观众"选一条"（"你会选哪个？看到最后"）
- **皮肤**：glass / 俯拍拆解台 / brutal
- **题材**：定投 vs 一次性、加息路径三种情景、预测市场概率
- ⚠️ 合规（TikTok 投放版）：历史回测数字当句跟"历史数据，不代表未来"+ 来源；不给胜率大字卡

## F09 `explained-60` · 60 秒看懂

- **节拍**：热点入题 + 概念名（0–4s）→ 一个具名比喻（4–20s）→ 机制推演动画（20–50s）→ 回到热点：所以这次意味着什么（50–70s）→ 一句话定义收尾（70–80s）
- **视觉语法**：机制段**必须是推演动画**（东西在流动/被填满/被抽走），不用文字卡；比喻有名字有金额（"小丽奶茶店"）
- **留存装置**：开头"看完你就知道为什么 X"
- **皮肤**：任意；贴纸线默认格式
- **题材**：做空、回购、逆回购、期权、熔断、指数纳入

## F10 `data-race` · 数据赛跑

- **节拍**：起点年份 + "猜猜谁会第一"（0–3s）→ 排名条随年份滚动赛跑（3–45s，按年份每 1.5–2s 一帧）→ 停在今天 + 一句解读（45–60s）
- **视觉语法**：bar chart race（条带 logo + 数值 count-up），年份大字在角落翻牌（SplitFlap）
- **留存装置**：中途一次超车（提前在开场预告"有一个会逆袭"）
- **皮肤**：terminal / swiss
- **题材**：市值排名变迁、各国国债持仓、ETF 规模、芯片份额
- 数据：离线 json，`public/data/`；不在渲染时联网

## F11 `scorecard` · 财报红绿灯

- **节拍**：结果先行（"超预期但盘后跌 8%"，0–4s）→ 实际 vs 预期逐项亮灯 🟢🔴（4–35s）→ 真正让股价动的那一项（35–60s）→ 指引与下季看点（60–85s）
- **视觉语法**：记分卡逐行翻牌、红绿灯逐个点亮、K 线（`Candles`）接盘后走势
- **留存装置**："5 项里 4 项超预期，为什么还跌"——答案在第 5 项
- **皮肤**：terminal（首选）/ swiss
- **题材**：财报快评（J 风格）、13F 持仓

## F12 `teardown` · 拆解（招股书 / 产品 / 商业模式）

- **节拍**：成品全貌（0–5s）→ 一层层拆开，每层一个数（5–70%）→ 拆到最里面的"真相层"（70–85%）→ 装回去，一句判断
- **视觉语法**：物件被拆开（俯视台面 / 爆炸图 / 剖面），每层贴一个标签
- **留存装置**：开头点出"第 4 层藏着一个问题"
- **皮肤**：俯拍拆解台 / swiss / 候选「等距沙盘」
- **题材**：IPO 招股书、商业模式、产品成本结构

## F13 `dialogue` · 双人问答

- **节拍**：小白提一个"笨问题"（0–4s）→ 来回 6–10 轮问答，每轮一个画面推进 → 小白最后用一句话复述（收）
- **视觉语法**：两个角色（Bobbie/Rich 贴纸，或两个对话气泡锚点），回答时画面切到推演
- **留存装置**：小白的问题就是观众心里的问题，每轮答完立刻追问
- **皮肤**：贴纸线 / brutal
- ⚠️ 合规：**不仿社媒帖/聊天截图呈现名人言论**（小红书 09-09 下架复盘）；角色是自家 IP

## F14 `clip-breakdown` · 原声片段拆解

- **节拍**：播放主角原声 3–6s（官方频道实拍）→ 暂停，逐句标注"他这句话的意思是"（数据佐证）→ 再播下一段 → 总结
- **视觉语法**：实拍画中画 + 暂停冻结帧 + 批注线
- **留存装置**：开头截一句最有争议的原话
- **皮肤**：黑底点阵 / 纪录片胶片 / terminal
- **题材**：鲍威尔/沃什发布会、CEO 财报电话会、马斯克访谈
- ⚠️ 素材只用官方频道、无水印；单段 ≤10s

## F15 `comment-qa` · 评论区提问

- **节拍**：一条真实评论当问题（0–3s）→ 拆成 3 个小问，每答完一个顺手抛下一个（3–75s）→ 一句话收 + "下一条答谁的问题"（75–90s）
- **视觉语法**：评论卡（自家账号评论区原评论，**隐去头像昵称**）→ Bobby 回答卡 / 推演动画
- **留存装置**：链式提问；观众天然认同"这也是我想问的"
- **皮肤**：任意；最适合 glass / swiss
- **题材**：FAQ 类（"为什么降息了还跌""ETF 和个股选哪个"）；天然就是"该问 Bobby 什么"的位
- ⚠️ 只用自家评论区（`own-account-comments-pull` 拉取），不伪造评论；不做仿社媒帖呈现名人言论（小红书 09-09）

## F16 `pov` · 第一视角

- **节拍**："你在 X 年 X 月买入了 Y"（0–3s）→ 情绪时间线 + 真实数据（3–45s）→ 关键决策点停帧"你会怎么做"（45–60%）→ 数据告诉你的答案（收）
- **视觉语法**：日历翻页、行情屏（代码自绘）、"你"的手机屏视角
- **留存装置**：自我代入
- **皮肤**：terminal / glass
- **题材**：追高、恐慌卖出、FOMO、熔断那天
- ⚠️ 合规高危：禁"回血/上岸/翻身"；不给收益承诺；海外投放版历史收益当句带"不代表未来"+ 来源

## F17 `money-flow` · 钱往哪流

- **节拍**："X 亿美元从 A 流到了 B"（0–3s）→ 逐段追踪每一跳（3–60s）→ 50% 处揭示最终落点（往往出人意料）→ 对普通人意味着什么
- **视觉语法**：地图 / 流向图，手绘路线逐段画出（`DrawSVG` / `Globe3D` 弧线），金额随流动 count-up
- **留存装置**：跟着钱走（"最后这笔钱去了哪"）
- **皮肤**：黑底点阵 + Globe3D / 候选「地图作战室」/ terminal
- **题材**：资金流向、ETF 申赎、供应链、关税转嫁、稀土
- 素材：地图数据离线 GeoJSON，不在渲染时联网

## F18 `i-am` · "我是 XX"拟物剧场（10-08 抖音 AI 科普调研）

- **节拍**："我是一张美债，今年有人拼命抛我"（0–3s）→ 每个角色一段第一人称自述（我从哪来 / 我遇到了什么 / 我会去哪），每段 12–18s → 结尾全员同框"合影"+ 一句结论
- **视觉语法**：物件拟人（贴纸/3D 道具 + 表情）、角色资料卡 HUD（名字 / 属性 / 当前状态数字）、场景标签条
- **留存装置**：身份代入 + 好奇"下一个角色是谁"；收藏型（元气小筑藏/赞 1.59）
- **皮肤**：贴纸线 / brutal / glass + 3D 道具（Coin3D 等）
- **题材**：美债、年终奖、一桶原油、一颗芯片、你的工资卡
- ⚠️ 拟物不拟真人；AI 生成角色加"AI 生成"角标

## F19 `inside` · 现实 ↔ 内部世界穿越

- **节拍**：现实一幕抛问题（"为什么咖啡又涨价了"，0–4s）→ 推镜钻进"内部世界"（期货交易所 / 供应链 / 央行资产负债表），场景标签 + 资料卡讲机制（4–60s）→ 拉回现实，问题有了答案（60–80s）
- **视觉语法**：实拍/照片 → zoom-through 进 MG/3D 世界 → pull 回实拍；每层世界一个场景标签
- **留存装置**：空间悬念（"里面到底发生了什么"）；评论钩子用**地域点名**（"你那边涨了吗"）
- **皮肤**：实拍 + glass / swiss；3D（IsoCity3D、FlowLine）
- **题材**：宏观 → 你的钱包（咖啡、猪肉、油价、房贷）

## F20 `ask-right` · 问错 vs 问对（Bobby 栏目）

- **节拍**：一个真实问题（0–3s）→ "很多人这么问"：模糊问法 + 没用的结果（3–20s）→ "换个问法"：精确问法 + Bobby 的有用回答（20–55s）→ 屏上打出"该问的那句话"供收藏（55–70s）
- **视觉语法**：左右/前后对照（指令卡 vs 结果卡）、红叉绿勾、问句大字定格
- **留存装置**：收藏型（"把这句话存下来"）+ 系列编号
- **皮肤**：terminal / swiss / glass
- **题材**：查财报、看资金流、比估值、查历史规律
- ⚠️ 国内版：只做信息查询类问题，不演示交易；小红书版不放 Bobby 界面（改成问句卡 + 结果复述）；问法禁"该不该买/目标价"

## F21 `near-miss` · "差一点"情绪数学（10-08 vibe知识大赏 T1）

- **节拍**：0–3s 具体到秒/楼/天的场景 + "差一点"（"如果那天你晚到 1 秒"）→ 3–8 三连排比卡 → 8–12 承诺"这是一道数学题" → 12–40 两三个硬数据块（每块一个大数字 + 一张图）→ 40–60 落到一个具体日期时刻的场景 → 60–90 两个带年份人名的实验 → 90–110 把数字叠成"小到不可能"的概率 → 110–120 兑现 → **最后 3s 对某个人做一件事**（"今晚给 TA 发条消息"）
- **视觉语法**：黑底 + 单一强调色（品红/金）、左上章节名 + 英文小标 + 公式、分岔树/网格/正态曲线、大数字计数
- **留存装置**：承诺是数学题（好奇）+ 结尾指向一个人（转发；样本转/赞 0.4–1.5）
- **皮肤**：候选 museum / terminal / 黑底点阵
- **题材**：金融里的"差一点"：差一天入场 / 少看一份财报 / 晚一年开始定投（不给收益承诺，用历史示意）

## F22 `chronicle` · 编年史博物馆（T3）

- **节拍**：0–4s 物件特写 + 一句哲学问句（骰子落下："运气能被计算吗"）→ 5–9 **片名卡早出** → 年份 HUD 推进 8–12 节，每节 8–15s = 年份 + 人物 + 一个可视化小实验/道具 + 右上文献角标 → 倒数第二节回扣开头物件 → 最后一句把历史落到"现在的你" → 文献线索卡
- **视觉语法**：深棕/藏青底 + 金描边 + 宋体一行字幕；纸质论文卡/古籍封面 3D 翻入；左上年份 HUD、右上文献角标；作者署名小字
- **留存装置**：年份推进的仪式感 + 收藏型（藏/赞 .21 最稳）

## F23 `simulation` · 可运行的模拟（T4；F08 what-if 的升级版）

- **节拍**：0–6s 问题与模拟同屏 → 6–16 规则 1–3 条 + **让观众先猜**（A/B/C 打在评论区 / "先想 3 秒"）→ 16–60 模拟跑起来（回合 HUD、实时数字/仪表/曲线、"等一下好像不太对"）→ 60–75 大数字揭晓 → 75–95 "最扎心的细节" → 95–115 简化版解释为什么 → 115–125 "这不是鸡汤，是一个数字" + 行动句 → 续集悬念 / 题名卡 + "画面由代码逐帧实时计算"声明
- **视觉语法**：模拟就是主角（3D 柱阵 + 基尼仪表 / 渗流网格 / 球体 agent 对局 / 红线配对），数字跟着变；用 `IsoCity3D / Bars3D / Particles3D / Ring`

- **题材**：100 人同样运气 30 年分化、37% 看多少家公司才出手、凯利仓位、复利 vs 定投；**只做示意分布，角标"历史示意 · 非收益承诺"**
