# 美术指导手册（art direction）

> 来源：GitHub 视频原生审美 skill 的提炼（hyperframes 讲解视频动效法则 / motionmaxxing 53 部专业短片对照表 / video-shotcraft 判例规则 / LottieFiles 动效原则 / anthropics frontend-design / taste-skill / hallmark），原文在 `vendor/`。
> **本文已按本账号规则改写**：和 `video-agent/rules/requirements.md`、品牌规范冲突的地方以本账号为准，冲突点逐条标了 ⚖️。
> 用法：分镜前读 §0–§4 定方向；写场景代码时查 §5–§7；成片前跑 §8 审片卡。

---

## §0 · 一句话

**审美 = 做了决定。** AI 味不是某种风格，是"没做决定时默认滑进去的地方"。每个选择（底色、字体、构图、转场、结尾）都要能用一句"因为这条片子是……所以……"说出来。说不出来就是默认，换掉。

## §1 · 开工前的方向单（分镜表之前，写进制作单）

1. **色板 4–6 个 hex**：底 / 主文字 / 次文字 / 唯一强调色 / 涨 / 跌。强调色只有一个意思，面积 ≤ 画面 3%。
2. **字体角色**：标题 / 正文 / 数字 各用哪款（`motionkit/type.js` 的 `PAIRS`），一条片子只用 **一款**表现型字体。
3. **每场构图清单**：每个场景写一个构图词（居中巨数字 / 左文右图 / 满版照片压字 / 俯视物件 / 时间轴横移 / 网格矩阵 / 分屏对撞…），**相邻不重复，全片 ≥3 种**。
4. **第一联想检查**：写下第一个冒出来的画面（"降息 → 剪刀剪利率""AI → 发光大脑"），然后再想两个，选不是第一联想的那个。
5. **遮 logo 测试**：把公司名/品牌色换成竞品，这条片子还成立吗？成立 = 没有为这条片子做设计。
6. **截图帧**：标出全片 2–3 个"观众会截图转发"的画面，它们必须是图形，不是一行字。

## §2 · AI 默认审美黑名单（看到就换）

| AI 默认 | 改成 |
|---|---|
| 近黑底 + 径向光晕 + 一个荧光强调色（"高级感"套餐） | 先问"底是黑的，是因为这条题材暗，还是因为黑显得贵"；浅底皮肤（swiss / brutal / 手账）至少占 1/3 |
| 米白 #F4F1EA + 陶土橘强调（另一个"高级感"套餐） | 手账线已经在这个簇里了——换皮肤时往远处走 |
| 紫→青、紫→蓝、橙→粉渐变；到处紫色发光 | 品牌紫是**实色元素色**；渐变只做光源（单方向、低饱和）；文字永不渐变 |
| 每场都是"标题 + 一张卡片"（PPT 页） | 舞台化：先想"这一拍**发生**了什么"（东西被推倒/被填满/被撕开），再想放什么字 |
| 小卡片漂在大面积空底上 | 主体占画面 40–60%，至少 3 层纵深（底 / 中景元素 / 前景主体） |
| 标题上方小字 kicker、全大写英文标签、01/02/03 编号（内容并非序列时） | 删。章节信息给 ChapterMark 一处就够 |
| 一行字里把一个词换色/斜体当强调（每句都这么干） | 全片强调色用在 ≤ 6 个词上；其余靠字号和位置 |
| 打字机光标逐字打出标题 | 词整块进场（2–12 帧间隔跟着口播），小位移 + 3–6px 模糊 4–8 帧内清掉。**例外**：terminal 皮肤的打字是题材语法 |
| 每场换一个新特效（粒子/故障/3D/光圈）炫技 | 一条片子 ≤ 2 种"特效级"手法，反复用、用出记忆点 |
| 所有元素同时淡入 | 一个入场原点、错峰 3,2,2,2 帧；同屏 ≥3 个元素时同时在动的 ≤1/3 |
| 屏上文字闪一下就走 | 每段上屏文字**至少停 2.5 秒**（75 帧）；停不够就别上屏 |
| 转场只是"切"（淡入淡出/硬切什么都不带） | **转场从内容里长出来**：每个切点写明"带过去的东西"——上一场的大数字飞到角落（Carry）、上一场缩成下一场的一张卡（NestZoom）、一条线变成下一场的地平线（Morph）、整块底色换掉（ColorFlood）；分镜表「镜头·接缝」列必须填这个元素 |
| 交叉淡化、白闪、黑场作为默认转场 | 硬切在速度峰值 + 同方向运动接力（§6） |
| 全片 emoji 当图标 | 皮肤决定：手账/贴纸/brutal 可用 emoji 当插画；terminal/swiss/glass 一律线稿图标或实物抠图 |

⚖️ **本账号白名单（motionmaxxing 判为 slop，但这里是强制项，必须保留）**：日期章、红 BREAKING（真突发时）、视频常驻标题、免责水印、片尾落版两行、Bobby 前置位、数据大字卡（金融片的核心信息载体，不是"stat slide"）。

## §3 · 字体

- **别再全片 PingFang 600**。它最粗只有 600、没有性格，是本账号最大的"模板感"来源之一。展示字体从 `motionkit/type.js` 挑（全部免费商用、已打包进 `public/fonts/`、`useFonts([...])` 加载）。
- 一条片子：**1 款展示字体 + 1 款正文 + 1 款数字**。不要两款风格相近的黑体并用。
- 字号底线（手机竖屏实测阅读）：可读文字 ≥ 画面高 3%（1440 高 → ≥ 43px；884 高 → ≥ 27px）；主文案 ≥ 5% H（1440 → 72px）。免责水印例外（本来就该淡）。
- 字重对比要大：标题 900 / 正文 500，别 600 对 700。
- 中文标题字距 0 到 -0.02em；拉丁大字 -0.03 到 -0.05em；数字一律 `tabular-nums`。
- 一屏只有一个巨数字；巨数字全片用 ≤ 6 次，每次都是"花钱"——count-up 结束落在**真实的非整数**上（"7.21 万亿"比"7 万亿"可信）。
- ⚠️ `"Hannotate SC"`、`"Kaiti SC"` 本机未安装会静默回退 PingFang（2026-10-08 实测）。

## §4 · 色彩与构图

- **色彩是事件**：大部分时间保持克制（底 + 墨 + 一个强调色），到 payoff 那一拍才让颜色"发生"——黄色只给全片最关键的 1–2 处（和品牌黄色纪律一致）。
- 中性色往品牌色轻微着色：不用纯 #000 / #FFF（黑底用 #050505–#0B0A10，白底用 #F1EEE7–#FFF4D6）。彩色面上的文字取该色相的深/浅色，不用灰。
- **按幕换底**：大章节切换时换底面（颜色/质感/明暗），用硬切或一个物件带过去；不要每场换一块色，也不要每场同一团光晕。
- 竖版（1080×1440）：内容纵向堆叠，主体锚点在 **y ≈ 0.42H**（≈605px）；少用左右分屏（除非一边面积 ≥ 另一边 2 倍）。
- 一帧一个主角，最多三个。同一卡片类型不连续出现 ≥ 3 场；卡片类场景 ≤ 全片 1/3。
- **骨架测试**：把所有文字遮掉，这一拍还能看出在讲什么吗？看不出 = 这一拍是 PPT。
- **幻灯片测试**：遮住全部文字看联系表，超过一半帧是"纯色底 + 一张卡片/一块字" = 这是一份 deck，改画面不是改字。

## §5 · 动效：缓动与节奏（数值）

| 项 | 默认值 | 来源 |
|---|---|---|
| 入场缓动 | `Easing.bezier(0.16, 1, 0.3, 1)`（expo-out 长尾减速） | hyperframes / motionmaxxing |
| 入场时长 | 中位 ≈ 10 帧；前 4–5 帧走完 60–72% 行程，之后 0.4–0.6s 长尾 | motionmaxxing M1 |
| 退场 | 时长 = 入场的 65–75%，**加速离开**（ease-in），是新动作不是入场倒放 | motionmaxxing M13 / LottieFiles |
| 错峰 | 组内总错峰 ≤ 15 帧（0.5s），间隔不均匀（3,2,2,2 帧）；≥3 个元素时同时在动的 ≤ 1/3 | LottieFiles choreography |
| 关键信息停留 | 落定后 ≥ 30 帧（1s）再动它 | video-shotcraft R2 |
| 揭示时机 | 内容跟着口播关键词**逐个**出现，别在场景前 25% 一次倒完 | hyperframes doctrine #2 |
| 弹簧 | ⚖️ 老规范"spring damping 11–14 弹入"降级：默认用 expo-out；明显回弹的 spring 每场 ≤ 1 处，给最重要那个元素。brutal 皮肤的回弹是皮肤签名，例外 | 调和 |
| 整屏冲击（震屏/闪白/Punch） | ⚖️ 开场拍按老规范强冲击；正片整屏冲击 **≤ 1 次/分钟、全片 ≤ 5 次**，留给真正的转折数字 | video-shotcraft R4 调和 |
| 呼吸浮动 | ⚖️ 用户规则"任何元素静止不超过 2 秒"不变，但兜底手段的优先级：**新事件 > 镜头缓推/漂移（`motionkit/camera.jsx`）> 元素呼吸**；呼吸只给装饰元素，不给主数字 | hyperframes vs 用户规则调和 |
| 运动距离 | 单段位移 ≤ 屏宽 1/3，更远要中间关键帧 | LottieFiles |
| 视差 | 前景 1.0× / 中景 0.5× / 背景 0.2×（`<Parallax depth>`） | LottieFiles |
| 速度感 | 来自加速度：一组元素入场越来越快（像发牌），然后停 0.5s | video-shotcraft R1 |

Remotion 写法：`interpolate(f - d, [0, 10], [0, 1], {easing: Easing.bezier(0.16,1,0.3,1), extrapolateLeft:'clamp', extrapolateRight:'clamp'})`。动作复杂（落地/撞击/甩出）时先按 `disney-animation-rule-skill` 拆姿态表（预备 → 发力 → 顶点 → 接触 → 过冲 → 稳定），再写插值。

## §6 · 切点与转场（hyperframes 切点法 → Remotion）

- **向量律**：上一场朝哪个方向离开，下一场就从反方向同速进来，切点落在运动中途；全片一个主方向（默认向左推进）。上 = 结论，Z 向前推 = 深入，Z 后拉 = 揭晓/落地。
- **cut-the-curve（默认接缝，替代淡入淡出）**：出场位移 ≈ 12% 屏宽，`Easing.in(Easing.poly(4))` 9 帧；入场 `Easing.out(Easing.poly(4))` 9 帧，起始 opacity 0.35；出场淡出在行程 25–30% 处完成。两段合起来就是一条 inOut 曲线，切点两侧速度相等。
- **穿越推进（zoom-through）**：出场 scale 1→1.2 + blur 0→10px（6 帧）→ 硬切 → 入场 0.75→1 expo-out 15 帧。用于"往下钻一层"。
- **反向拉远**：1→0.8 出，1.25→1 进。只给 payoff 拍。
- 模糊量：文字 10px，整屏 18–20px；模糊加在外层容器，不加在每个子元素上。
- **按幕换底**：大章节切换时用 `ColorFlood` 换整块底色（不是换一团光晕），颜色从皮肤的幕色候选里选，一幕一色不混；吉祥物/共享元素跨过切点把两幕缝起来
- 大章节转场：皮肤自带 `Wipe`（terminal 扫描带 / swiss 百叶 / glass 玻璃横扫 / brutal 色条），全片 ≤ 10 次（老规范不变）。
- **禁用**：星形光圈、移轴、镜头光晕贴图、合页翻转；故障 RGB 分离只用于"系统出错/数据异常"语义。
- 光漏（light leak）：叠在硬切上，不缩短时间轴；光斑尺寸要大于画面（≥ 2400px）。

## §7 · 镜头语言（`motionkit/camera.jsx`）

- 每个超过 3 秒的场景包一层 `<Camera move>`：push（默认）/ pull / panL / panR / rise / drift；相邻场景换不同 move。
- 口播重音（最大数字落地、"但是"转折）用 `<Punch at={[帧]}>`，计入整屏冲击配额。
- 纵深：背景层 `<Parallax depth={0.2}>`、主体 `depth={1}`、前景装饰 `depth={1.4}`。
- 快甩切（whip）：`useWhip(cutFrame, dir)` 套在切点两侧场景外层，6 帧方向模糊。

## §8 · 审片卡（成片/关键帧交付前；**不许自评，派一个干净上下文的 subagent 看图打分**）

把 `--frame=0` + 每场中段一帧 + pace_check 报告交给 subagent，逐项 PASS / FAIL / 有理由豁免：

1. 遮字测试：遮住文字，>50% 帧是"纯色底 + 一块卡"？
2. 构图：相邻场景同构图？全片构图种类 <3？
3. 主角：有没有"小卡片漂在空底上"（主体 <30% 画面）？
4. 字体：展示字体 >1 款？可读文字 <3% H？还在用 PingFang 当展示字？
5. 颜色：强调色 >1 种意思？出现紫青渐变/满屏紫光？黄色用了 >2 处？
6. 动效：默认弹簧回弹到处都是？整屏冲击超配额？
7. 转场：交叉淡化/白闪当默认？
8. 节奏：pace_check 有静止段 >2s、或 5 秒窗无事件？前 10 秒事件 <5？
9. 第一联想：有没有"AI→发光大脑、降息→剪刀"式第一联想画面？
10. 截图帧：能指出 2 个值得截图的画面吗？
11. 本账号白名单项都在吗（日期 / 免责 / Bobby 前置位 / 落版）？

修排名前 3 的 FAIL → 重渲 → 再看一次。**两轮为限**，别无限打磨。
