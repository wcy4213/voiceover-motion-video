# 拓宽：题材 × 输入途径 × 输出途径 × 节目化

> 出发点：现在的生产是"一种题材（美股投研/投教）× 一种输入（用户朗读的口播）× 一种形态（口播 + 动效）× 两个平台"。每个乘数都可以变大。
> 护栏不变：一切内容对齐业务指标（注册/促交易，memory content-growth-rules）；Bobby AI 露出走官方口径；国内平台合规（不荐股、不演示交易、不伪造名人）。

---

## A. 题材：从"美股投研"往外画同心圆

| 圈层 | 题材 | 为什么能做 | 推荐格式 / 主技术 | Bobby 怎么出现 |
|---|---|---|---|---|

| 2 圈 · 历史上的今天 | 金融史日历（熔断、黑色星期一、泡沫） | 可日更、可系列、选题不愁 | F07 timeline · 胶片/宣纸候选 | "Bobby AI 把这次和上次的数据并排拉了一遍" |
| 3 圈 · 角色 IP | Bobbie/Rich 连续剧（每集一个金融陷阱/概念） | IP 记忆点、跨平台复用、适合小红书收藏 | 贴纸管线 · F13 dialogue | 落版 + 角色手机屏亮 icon |

**怎么选**：每周排产按 70 / 20 / 10 —— 70% 核心线保底，20% 1 圈试新题材，10% 2–3 圈做实验（与 memory tt-trading-app-benchmark 的配比思路一致）。实验条在台账里标"实验"，两周后看数据决定是否转正。

## B. 输入途径：一条视频可以从哪里开始

| 输入 | 现状 | 怎么接入 |
|---|---|---|
| 用户剪映朗读的口播 | ✅ 主流程 | — |
| 只有稿 → 自动配音 | 剪映 TTS（用户手动） | Qwen3-TTS 音色克隆已在 `podcast_dub` 验证（memory podcast-dubbing-pipeline），可做"固定音色自动配音"省掉朗读来回；中文正片仍以剪映音色为准，先在实验条用 |
| 新闻/文章/链接 | 人工 | `usstock_news.py` 聚合器已有 7 信源 → 自动出选题卡 → Step 1 写稿 |
| 一组数据 | 人工 | `stock-line-video` agent（ticker → 折线视频）+ `Candles`/data-race 模板 → **模板化日更**（每日 60s 数据早报，人工只审） |
| App 录屏 | ✅ 录屏短片流水线 | — |
| 官方实拍/发布会 | 开场素材 | F14 原声拆解格式 |
| 播客/长视频 | 未做 | 转写 → 找 20–55s 能独立成立的段 → 新写第一句 → 竖屏重排（思路来自 youtube-agent-skill 的 yt-shorts） |
| AI 生成 | 未做 | chatcut `video-gen`（需 /mcp 授权） |

## C. 输出途径：一个母版，多种成品（一鱼多吃）

| 成品 | 从母版怎么来 | 备注 |
|---|---|---|
| 抖音精华版 60–100s | 删减分镜（保留 25 秒线 + 50% 钩子 + 75% 大刺激） | 现状 |
| 小红书视频完整版 | 母版 | 去 Bobby 截图/名人抠图/CTA（合规差异） |
| **小红书图文轮播** | 从母版挑 6–9 个"记忆点镜头"静帧 + 每张一行字 | 小红书图文常比视频吃收藏；成本几乎为 0（`still --frame=N` 批量出） |
| 视频号 | 抖音版 | 发布时机/话术另配 |
| TikTok / Shorts / Reels | 1080×1920 重排 + 英文 timeline | 落版 ≤1.5s、回环 |
| YouTube 横版 | 逐场景重排到 16:9（memory youtube-en-16x9-pipeline） | 加章节 |
| B 站长版 | 母版扩写 | 悬念给两次骨架 |
| 社群卡片 / 封面集 | 静帧 | 社群两框文案同时出 |

## D. 节目化（让观众"追"而不是"刷到"）

- **栏目化**：每条片子带一个 2–4 字栏目章（"财报 T-1""一个数""谁干的""历史上的今天"），固定片头位置但不固定构图（防首帧同质化）。
- **编号与预告**：系列片编号（#1 #2…），片尾一句"下一期讲 X"（开环跨视频）。
- **固定时段**：每周固定几个发布槽（memory social-calendar-builder 出月度日历）。
- **评论区驱动**：每条置顶评论问一个问题，下一条 F15 comment-qa 回答它 → 评论数和下一条选题同时解决。
- **模板化日更 + 人工精品**：数据早报全自动（模板 + 数据源 + pace_check 自动 QC），人工精力只给每周 2–3 条精品。

## E. 抖音「AI vibe 视频」调研结论（2026-10-08，585 条 + 27 条逐条拆解）

完整报告与原始数据：`<benchmark-data>/report.md`（rows.json 含作者信息）。

1. **"AI × 财经/科普动画"是空赛道**：搜"AI 财经 动画"只有 21 条、点赞中位 162；同期 AIGC 短片点赞中位 1.9 万、AI 工具类收藏/赞 0.64。本账号的动效能力正好落在这个空位上。
2. **小号能爆**：≥10 万赞的 71 条里 24 条来自 <5 万粉账号——起量看内容设计，不看粉丝底。
3. **互动来自设计，不来自剪辑速度**：27 条里节奏数字和互动率基本不相关。高互动样本的共同点是：能答的问题、身份/地域代入、可收藏的清单、系列编号、故意留槽点（`craft/retention.md` §2.6）。
4. **最能借的叙事装置**：①"我是 XX"拟物第一人称（F18）②现实 ↔ 内部世界穿越（F19）③指令 vs 结果对照 → "问错 vs 问对 Bobby"（F20）④固定双人搭档问答（F13，可直接用 Bobbie/Rich）⑤口诀歌（卡片跟节拍切）。
5. **最能借的包装**：开场两行大字问句关键词标红 / 反向钩子；场景标签 + 角色资料卡 HUD；"AI 生成"角标；**制作参数片尾卡 → "数据由 Bobby AI 整理 · 用时 XX 秒"**（自然满足 Bobby 露出）。
6. **蹭官方活动话题**：带 #抖音ai创作大赛 / #ai创作浪潮计划 / #vibecoding大赏 的点赞中位 2.4 万 vs 8649（相关，未证因果）——实验条可以挂。
7. **只能 AI 视频生成的画风**（皮克斯风 3D 叙事、写实微短剧、动物过人类生活、梦核巨物、一镜到底）：走 chatcut video-gen（需 /mcp 授权），少量镜头掺进动效片做"模式打断"，不整片依赖。
8. **不碰**：讨花讨礼物式诱导互动（评论被🌹刷屏）、撒钱"财富快递"模板、性别对立情绪。

新路线（进 §A 的 1–3 圈）：我是一张美债 / 我是你的年终奖；一杯咖啡 → 巴西天气 → 期货 → 价签（评论用地域点名）；"数据下雨"可视化系列；"问错 vs 问对 Bobby"栏目；生活口诀歌（个税 7 档、五险一金）。
