# 范式 B · 知识体系型(对标:刍狗老张)

> **矩阵归属**:金融深度类的"系列化"风格,主要用在格子④(长视频·系列教学)。

适合**金融常识科普、系列化教学、投资方法论**类选题。核心打法:系列化运营(第 01/02/03 期)、唠家常式的口语讲解、固定人设的开头和结尾。单条体量偏大(中长视频,3000-6000 字),适合做成专栏。

## 节奏骨架(系列教学版)

```
1. 系列锚点 + 致谢   开头点明"第 X 期 / 本系列",承接上期,致谢催更
2. 抛核心问题        用一个外行也好奇的问题切入("你知道人民币是什么吗?")
3. 唠家常式铺垫      用生活类比降低门槛("要是让我管人民币,直接每人发 100 万…")
4. 主体讲解          分点把概念讲透,边讲边用图表/类比(口播里常说"这张图…")
5. 预告下期          "下期咱们一起看看…",维持系列追更
6. 固定人设收口      口头禅签名 + "点个关注,咱们一起从小白开始搞懂金融与投资"
```

## 开头句式库

这套账号开头有两类:**系列承接式**和**反差钩子式**。

系列承接式(建立专栏感、回报老观众):
- "感谢大家喜欢这个系列。之前咱们讲了 A 股和美股,今儿咱们接着讲港股的大公司。"
- "上期视频数据爆了,特别感谢大家厚爱,也收到大家各种催更,连夜加更赶出这一期。"
- "从零开始搞懂金融与投资,欢迎收看本期初识金融业,我是楚国老张。"

反差钩子式(单期也能抓人):
- "要是让我管人民币,直接给咱每人发 100 万,人人都当百万富翁,股市暴涨 10 倍多好。哎,想法好像有点天真了…"
- "美债危机火烧眉毛,美联储还我行我素拒不降息。这么个紧要关头,特朗普为什么力推稳定币?"
- 固定开场白:"哈好好哈。这是工商银行自 06 年上市以来的月线图…"(以一张图起手,极具辨识度)

## 讲解技巧:把专业的讲成大白话

- **极端假设法**:先抛一个荒谬的极端设想,再说"哎,想法有点天真了",自然引出正确机制。(讲货币超发时用"每人发 100 万")
- **衙门/治水类比**:把抽象金融制度翻译成生活里的具象物("中国的银行业和治水的衙门口")
- **图表口播化**:口播里反复指图——"这张图是过去 70 年美国债务增长曲线""20 年时间从 400 美金涨到 2800 美金"
- **数字带年化**:讲投资品必给年化,建立专业感("20 年上涨 5 倍,年化收益率 9%")
- **宠粉式总结**:结尾常"作为一个宠粉 up 主,给伸手党总结一句话…"

## 系列化运营的钩子

- 期数编号 + 系列名嵌进标题:【初识金融业 03】【复利工程 02】【下班聊聊】
- 每期结尾**明确预告下期内容**,把概念拆成连续剧:"下期咱们看看银行怎么赚钱,把存款准备金、货币创造、M0M1M2 一并说清楚。"
- 开头致谢上期数据/催更,形成正反馈循环。

## 固定人设收口(签名)

这套账号最强的记忆点是**固定结尾签名**,务必保留:

- 口头禅签名:"天地不仁,以万物为刍狗,我是刍狗老张。"
- 系列号召:"点个关注,咱们一起从小白开始,搞懂金融与投资。"

> 写 B 型脚本时,结尾必须用对标账号的固定签名收口——这是系列化人设的核心资产,不能换成普通升华句。如果是为新账号写,要先帮其设计一句可复用的人设签名。

## 语气标记

第一人称强(我/咱们),像私下跟朋友唠("今儿""咱们""哎呀""说人话")。专业但不端着——会自嘲、会宠粉、会用大白话翻译术语。**重要提示前置**:涉及投资品会主动加免责("重要提示,本视频中所有曲线投资品都是…")。

## 合规要点(投资类系列尤其注意)

- 主动加风险/免责提示,不做具体买卖点推荐。
- 讲方法论(择时、风控、复利)而非荐股。
- 涉及具体投资品时用"复盘/原理"框架,不诱导操作。

## 一条完整样例的骨架(以"钱能随便印吗【初识金融业 05】"为例)

1. 系列锚点:第五期,一起了解中国央行和人民币之锚
2. 反差钩子:"要是让我管人民币,每人发 100 万…哎,想法有点天真"
3. 唠家常铺垫:为什么不能随便印 → 通胀机制大白话
4. 主体讲解:人民币之锚、央行角色,配图讲解
5. 预告:下期讲银行怎么赚钱,M0M1M2 说清楚
6. 签名收口:"天地不仁,以万物为刍狗,我是刍狗老张。点个关注…"

## 进阶变体:硬核教学 / 课程化专题型(对标 小雷大智慧)

当选题是**一个需要系统讲透的硬核知识**(财报、期权策略、技术指标、经济学原理),可以把 B 型升级成"课程化"打法——像开一门课一样,分专题、编课时、零基础推进。这是系统教学头部账号的做法,单条体量大(5000 字以上),适合长视频和系列。

### 硬核教学型的独特手法

1. **课程化/专题化命名**。把内容封装成"课程"而非"视频":"财报全攻略 01""经济学入门第九课""八大期权策略详解"。给观众"在系统学一门课"的感觉,带动追更和收藏。

2. **零基础人设 + 承诺**。开头明确"零基础,从零开始学",降低门槛、给安全感:"还是老规矩啊,零基础,我们从零开始学。" 教学人设亲切("来,各位""宝子们")。

3. **硬核但不劝退的拆解**。把难概念(MACD 原理、量价关系、除权除息)拆成可消化的小块,先讲"是什么"再讲"为什么",边讲边强调"这个点有点难,我多解释一遍"。

4. **互动测验/自检**。用题目调动参与感:"5 道题检验你的投资天赋""你听完就知道这视频的含金量"。让观众边看边自测。

5. **知识点升华收口**。结尾把一个技术点上升到认知层面——比如讲完成交量,落到"任何指标都要结合量价一起看,别迷信单一指标";讲完财报,强调"财务报告和财务报表是两个东西"这种易错点澄清。常带"先别跑,我再强调一遍"的二次强化。

### 硬核教学型骨架(课程版)

```
1. 课时锚点      "这是第 X 课 / XX 全攻略 01",承接专题、致谢呼声
2. 适用人群+承诺  谁该学、零基础也能懂
3. 概念定义       先把"是什么"讲清(给定义、举生活例子)
4. 原理拆解       再讲"为什么"(底层逻辑,难点多解释一遍)
5. 实操/计算      怎么用(操作步骤、计算示范、盈亏区间)
6. 易错点澄清     点出大家普遍搞错的地方
7. 升华+预告      上升到认知层面 + 预告下一课
```

### 硬核教学型与基础 B 型的区别

基础 B 型(刍狗老张)偏"唠家常式常识科普";硬核教学型(小雷)偏"系统开课式硬核教学",知识更深、结构更像教材、更强调"从零到精通"的课程感。两者都系列化、都有固定教学人设,但硬核型的知识密度和系统性更高。

> 适合做成"专题课"的选题:财报分析、估值方法、技术指标、期权/期货策略、经济学原理、资产配置——凡是"需要按顺序学、能拆成多课时"的硬知识。
