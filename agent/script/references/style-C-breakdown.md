# 范式 C · 拆解科普型(对标:阿泰 / 阿Test正经比比)

> **矩阵归属**:金融深度类主用风格之一。短视频=格子③(一个反常识点打透)、长视频=格子④(超长层层拆解)。

适合**商业模式拆解、智商税揭穿、原理科普**类选题。核心打法:用一个反常识切口切入,把"为什么"一层层拆到底,常带一个鲜明态度结论。体量弹性大(短的 1300 字,长的可到 5000-6000 字深度拆解)。

## 节奏骨架(拆解版)

```
1. 反常识切口     用一个反直觉现象/极端对比/惊人数字开场
2. 抛真问题       "那你肯定好奇…为什么会这样?" 把好奇心点燃
3. 先破后立       先说大众的直觉答案,再说"其实不是这样"
4. 层层拆解       一层一层往下挖:表象 → 机制 → 真正的底层原因
5. 给态度结论     不和稀泥,给一个明确判断(是不是智商税 / 壁垒在哪)
6. 收尾留白/升华   回到开头的问题,给干净结论或抛一个开放追问
```

## Hook 句式库(切口要"反直觉")

- **极端对比/假设**:"如何把 30 万现金变成 3300 万?假如 20 年前你手握 30 万…"
- **反差实验**:"让两名外国大学生和中国五年级小学生比答题,结果会怎样?"
- **反常识数字**:"携程 25 年又赚翻了,净收入 624 亿,净利润 333 亿,净利率高达 53%。"
- **算账打脸**:"某款 19.9 块的人参水,五年人参 2 块钱,玻璃瓶比人参还贵。"
- **冷知识起手**:"任天堂起家时其实不是做游戏的,而是开情侣酒店。"

> C 型 hook 的关键不是"炸",而是"勾"——抛一个让人下意识想知道答案的反常识点。

## 拆解的核心方法:先破后立 + 层层下钻

这是 C 型区别于 A 型的关键。A 型是"揭秘",C 型是"拆解逻辑":

1. **先给大众的直觉答案**:"那肯定好奇携程为何如此暴利?是不是我们每 100 块房费他赚 50 块?"
2. **立刻推翻**:"哎,其实不是这样的。"
3. **拆第一层**:300 多亿利润里超过一半来自投资收益,而非主营。
4. **拆第二层**:佣金率其实只有 5-6%,净利率约交易额的 1%。
5. **拆到底层**:真正的壁垒是 20 年积累的库存直连和履约能力。
6. **给结论**:"携程的成功不是靠暴利或砸钱买流量,而是靠日复一日做出的信任。"

## "说人话"翻译技巧

- 每讲一个专业概念立刻翻译:"说人话就是,你在携程上看到的房是真实能锁定的。"
- 用算账代替结论:智商税类选题直接把成本拆给观众看("3 块成本卖 19.9")。
- 用类比降维:把抽象商业模式比成生活场景。

## 给态度的结论(C 型的灵魂)

C 型不和稀泥,敢下判断,但判断是**基于拆解后的事实**而非情绪:

- 揭穿型结论:"养生水的功效到底是有科学依据,还是信则有不信则无?"(把判断权交还观众,但事实已摆明)
- 肯定型结论:"携程真正的壁垒,是日复一日做出的信任。"
- 方法论结论:"投资就是这样反人性的,有时候慢就是快;做简单的题和耐心,就是最快的捷径。"

## 收尾技巧

- **回到开头的问题**:开头抛的反常识问题,结尾给个干净结论,形成闭环。
- **升华到普适道理**:从具体案例抽出一条可迁移的认知("80% 的时间是垃圾时间")。
- **开放追问**:留一个让人想评论的问题(智商税类常用)。

## 语气标记

口语 + 网感:"你想啊""哎""说人话""那你肯定好奇""浅算一下"。整体是**理性拆解者**——有网感但讲逻辑,信息密度高,擅长把复杂的事拆得清清楚楚。适合信息量大的深度选题。

## 软广识别提醒(重要)

C 型这套手法极易被用于**科普式软广**(借科普外壳植入品牌)。判断标准:
- 标题是否绑定具体品牌/型号(如"理想 i6""尚界 Z7")
- 全片是否最终服务于单一品牌的卖点
- 结尾是否落到"这台车/这款产品"的购买理由

写 C 型时若选题是中立商业分析(如携程模式拆解、智商税揭穿)是正常内容;若变成为单一品牌背书,就是软广,需明确标注。

## 一条完整样例的骨架(以"中国酒旅为什么离不开携程"为例)

1. 反常识切口:携程净利率 53%,比茅台还能打
2. 抛真问题:是不是每 100 块房费赚 50 块?
3. 先破后立:其实不是——超半数利润来自投资收益
4. 层层拆解:佣金率仅 5-6% → 净利率约交易额 1% → 真正壁垒是库存直连
5. 给结论:壁垒不是暴利,是 20 年的服务履约和信任
6. 收尾:日复一日做出的信任,才是真正的壁垒

## 2026-06-11 增补:C 型的长视频打法(阿泰万字《最适合普通人的投资指南》提炼)

阿泰首次出现 C 型 × 长视频(格子④,约 6000+ 字)样本,验证了 C 型拉长的三个关键:

1. **一组贯穿类比当骨架,而不是更多论点。** 全篇用两个类比撑 10 分钟:"投资跑步机"(通胀=跑步机速度,简单难度 CPI 2.15%/困难难度 M2 12.9%)和"会不会下蛋的鹅"(现金流资产 vs 纯价差资产)。长视频不是论点×3,是**同一个类比反复回扣、层层加码**——每个新概念都翻译回跑步机/鹅的语言,观众永远不迷路。
2. **开场用"开上帝视角的爽文推演"做 hook**(30 万→买房→卖房 all in 大A→清仓换黄金→3300 万,年化 19.1% 跟巴菲特五五开),先给爽感再自己拆台("这是开了上帝视角,要么踩了狗屎运")——爽感留人,拆台立信。
3. **长视频要埋"收藏点"和"互动点"**:中段明示"如果你是家里管钱的,可以先点收藏";多处"打在公屏上""你们觉得难不难"现挂。完播撑不住 10 分钟,就让收藏和评论接住流量。

另:阿泰自曝"4 年投了 50 万乐高被一个报告忽悠"——真实亏钱经历是 C 型最强的信任资产和毛边素材(见 anti-ai-flavor 第二法)。
