# 去 AI 味专项 · 毛边注入手册

> **为什么有了 AI 味自查清单,稿子还是 AI 味?** 因为旧清单是"负面清单"(别用排比、别用八股、别用"赋能"),但 AI 味的本源不是用了坏词,而是**缺少真人说话的"毛边"**。规则全部合规、句句正确高效的稿子,恰恰最像 AI。这份手册讲怎么把毛边"种"回去。全部手法提炼自 460+ 条真实跑量口播。

## 一、先认清:AI 味的五个真正来源(不是用词,是质地)

把一篇真人口播和一篇 AI 稿并排放,差异不在词汇表,在这五处:

1. **句长太均匀。** AI 每句 15-25 字,波动极小。真人句长剧烈震荡:阿泰讲完一大段跑步机类比,突然一句——"活着。"两个字单独成段。北大研哥:"那需求在加速,供给跟得上吗?跟不上了。"三个字收掉一整段悬念。
2. **每段同一个模具。** "观点→数据→换算→小结"四件套每段满配,像流水线盖章。真人是不均匀的:有的数字换算三层,有的数字直接甩过去不解释;有的段落只有一句话。
3. **转场太丝滑太书面。** "接下来""与此同时""值得注意的是""综上"——真人转场就是一个"那"、一个"哎"、一句"说回来"、"还有个事儿"。
4. **没有"我"在场。** AI 稿是无人称的知识播报。真人脚本里全是第一人称痕迹:"今天早上啊我刚睡醒,韩国那边又炸了"(北大研哥);"像我之前用 4 年时间投资了 50 万乐高,就是被一个报告给忽悠了"(阿泰自嘲真实亏钱经历)。
5. **太圆满,没有一句"废话"。** 真人口播里有大量功能性冗余:重复要点、缓冲口头禅、自我插注。这些"废话"是节奏的呼吸。AI 把它们全优化掉了,于是稿子高效得不像人。

> 一句话:**AI 味 = 均匀 + 无人称 + 零冗余。去 AI 味 = 制造不均匀 + 把"我"放回去 + 留几口呼吸。**

## 二、毛边注入七法(写完初稿后,逐条做一遍)

### 1. 句长破坏
每 4-6 句,必须出现一个 **≤6 字的独立短句**(可单独成段,口播时就是一个停顿+重音)。真实样本:"活着。""没房了。""扩产。""舍得。""跟不上了。""光纤顶上。"
做法:找到每段最想强调的那个词/结论,把它从长句里拽出来单独成句。

### 2. 把"我"放回去
每篇至少 1-2 处第一人称真实痕迹。三个安全来源(**不许凭空编造经历**):
- **工作痕迹**:"我翻了一下他最新的 13F""这数据我反复核了两遍""我上条视频专门讲过"
- **账号人设的既有真实素材**(阿泰的乐高、老张的选修课)
- **临场状态**:"今天早上我刚睡醒""说实话这期我准备了很久"
判断处加"我觉得/我个人觉得/我认为最重要的信号是"——把判断挂在人身上,而不是悬空的"值得注意的是"。

### 3. 护栏句(主动泼冷水,反而增信)
真人讲数据会主动标注局限,AI 只会自信输出。真实样本:
- "但啊这也是猜测啊,并不确定啊。"(北大研哥讲台积电代工)
- "注意啊,这是十年前的数据了。"(小白学财经)
- "所以这二十倍并不都是它的收益……大家参考一下就好,不用太去神话这位老哥。"(呱呱蛙讲 13F)
每篇至少 1 处:在最容易被质疑的数据/推断旁边,主动说一句"这有水分/这是猜测/口径要注意"。

### 4. 互动现挂
1-2 处直接对观众喊话,制造直播感:"打在公屏上""你们觉得难不难?""你说这个花稀缺吗?""您对 XX 怎么看,评论区聊聊"。位置:抛问题处、关键判断前。

### 5. 转场降级
全文搜一遍这些词并替换:"接下来→那""此外/另外→还有个事儿/再说一个""与此同时→这时候""值得注意的是→注意了哈/但有意思的是""综上/总而言之→所以说"。书面转场词清零。

### 6. 密度故意不均
- 挑 1-2 个数字**不换算直接甩**(全换算=模具味;真人有时候就是甩个数过去)。
- 留 1 个段落只有一两句话。
- 最核心的论点讲两遍:第一遍正常讲,隔几段后用近似原话再扣一次。**真人强调靠重复,AI 强调靠堆形容词。**

### 7. 删总结句
AI 习惯每段结尾来一句"由此可见/这说明了"。逐段检查:把段尾总结句删掉,稿子若反而更顺,说明它是 AI 赘肉。全篇只在收尾处保留一次升华。

## 三、技巧清单的使用红线(对 micro-techniques 的重要补丁)

micro-techniques 里的武器(数字换算、自问自答、反差句、钩子句)是**弹药库,不是每段必打的配方**。机械满配 = 另一种 AI 味("模具味")。配额参考:

| 技巧 | 1500 字短视频用量 | 超过即模具味 |
|---|---|---|
| "什么概念/相当于"换算 | 2-3 次(只给最关键的数字) | 每个数字都换算 |
| 自问自答 | 2-4 次 | 每段都"那为什么呢" |
| "表面/本质/背后"反差句 | 1-2 次 | 段段反转 |
| 结尾互动三件套(金句+留白+关注引导) | 收尾用一次 | 中途反复出现 |

> 判断标准:**范文里的他,这一段会用这招吗?** 用不用某个技巧,以所选风格范文的真实密度为准,不以 checklist 为准。

## 四、AI 味终检三问(交稿前最后一关)

1. **句长方差**:随机抽三段朗读。有没有 ≤6 字的炸点短句?最长句和最短句差距够不够大?(全是中等长度句=不合格)
2. **指纹句**:全篇有没有至少一句"只有这个人/这个账号会说"的话?(人设口头禅、自嘲、个人判断。删掉署名后还能猜出是谁的稿子,才算有指纹)
3. **删除测试**:随便删掉一个段尾总结句、一个形容词,稿子是否更顺?是→继续删,直到删不动。

三问全过,再走 SKILL.md Step 4 的常规自检。

## 五、速查:书面腔 → 口播腔替换表(高频)

| 书面腔(AI 高发) | 口播腔(真实语料) |
|---|---|
| 值得注意的是 | 注意了哈 / 但有意思的是 |
| 接下来我们分析 | 那 / 咱们再看 |
| 由此可见 / 这表明 | 所以说 / 你看 |
| 然而 / 但与此同时 | 但是哈 / 可问题是 |
| 显著提升 / 大幅增长 | 直接翻倍 / 涨疯了 / 一夜之间 |
| 综合来看 | 这么算下来 / 掰着指头算 |
| 不仅 A 而且 B 更是 C | (拆成三句短句,或只留最狠的一个) |
| 在这个时代,我们每个人 | (删。升华只升一次,且必须落在具体的人/事上) |
| 首先…其次…最后 | 第一个 / 再一个 / 最后说个最狠的 |
| 某种程度上 / 一定程度上 | (删,或改成"多少有点") |
