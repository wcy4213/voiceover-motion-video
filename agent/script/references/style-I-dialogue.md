# 风格 I · 双人对话体(对标:方师傅《当你有个懂金融的老爸》)

> **这是格式维度上的新物种**:A-H 全是单人口播,I 是**双人对话剧本**——一个"懂行的"(老爸/分析师)+ 一个"会替观众问的"(子女/小白)。观众不是在听课,是在旁听一场饭桌聊天。提炼自方师傅 19 条真实跑量对话稿(84-97 期)。

## 一、定位与适用

- **格子**:金融热点 × 短视频(60-180 秒)为主;一期只讲透**一个**概念或一条逻辑链。
- **选题**:适合"有一个反直觉答案"的题——猪周期、稳定币、低利率的真正目的、美债收益率飙升、AI 公司做假账。热点事件 + 底层机制 = 最佳配置。
- **RockFlow 适配**:Bobby AI(人格化 IP)天然适合做"懂行的那个人";对话体能把合规敏感的判断包在"老爸的饭桌闲聊"语境里,比单人断言更软。

## 二、角色分工(铁律)

| 角色 | 职能 | 台词特征 |
|---|---|---|
| **提问者(说话人 1)** | 替观众发问、说出大众直觉(用来被推翻)、做类比迁移、接梗 | 短句、口语、带情绪("那不是排骨也便宜了吗""这话有点过分了吧") |
| **讲解者(说话人 0)** | 抛钩子、反问回去、给机制、给数据、给收尾判断 | 永远不直接灌输——先反问,等提问者给出"普通人答案",再顺着推演 |

**核心机制:讲解者用反问把提问者(=观众)拖进推理。** 真实样本节奏:
```
讲解者:今年猪肉史诗级暴跌,每斤不到五块钱。          ← 热点开场(一句话)
提问者:那不是排骨也便宜了吗?越便宜越好呀。            ← 大众直觉
讲解者:如果对买猪肉的是好事,那谁吃亏了呢?            ← 反问 1
提问者:那肯定是卖猪肉的呀。                           ← 普通人答案
讲解者:那我问你,如果猪价涨到 50 一斤,你是养猪的,怎么多赚钱? ← 反问 2(角色代入)
提问者:那肯定多买小猪仔,赶紧养大卖钱嘛。              ← 观众自己推出了周期的第一环
讲解者:所以一年前所有养猪的都是这么想的……             ← 顺着观众的答案推演机制
```

## 三、节奏骨架(90-150 秒,全篇 25-45 个对话轮次)

```
[热点开场]   讲解者一句话抛热点/反常识现象(≤20 字)
[直觉上钩]   提问者说出大众第一反应(这个直觉后面要被推翻)
[反问链]     讲解者连续 2-3 个反问,每个反问让提问者代入一个角色
            (如果你是养猪的/如果你是消费者/如果你是央行)——观众跟着自己推演
[机制展开]   讲解者给出完整逻辑链 + 1-2 个具体数字(成本 2000 卖 1500,每头亏 500)
[类比迁移]   ★招牌拍点:由**提问者**主动把机制迁移到另一个领域
            ("我怎么感觉把养猪换成房子也是一样的呢?")——让观众觉得"我也想到了"
[升维]       讲解者把话题抬到更大的标的(猪周期→互联网泡沫→AI 资本开支)
[收尾金句]   讲解者一句人性/规律层面的断言收口:
            "便宜是上一轮痛苦的结果,昂贵是下一轮痛苦的开始。"
            "人总是在高点时最自信,低点时最悲观。"
```

## 四、对话写作铁律

1. **提问者不许是捧哏工具人。** 它的台词必须是观众真会想的话,包括"杠"("这话有点过分了吧,人家也是辛辛苦苦养猪的呀")。有一两次小抬杠,对话才活。
2. **讲解者不许连续超过 5 句不被打断。** 超了就拆,塞一句提问者的接话/追问/惊叹。
3. **每轮台词短。** 单轮 ≤2 句,多数 1 句。对话体的呼吸就是高频换人。
4. **数据降密。** 对话体一期只扛 3-5 个数字,每个数字都要嵌在推理里,不许报菜名。
5. **类比迁移必须给提问者。** 这是本体式最聪明的设计:把"举一反三"的高光时刻让给观众的代言人。
6. **收尾不引导关注也行。** 对话体的收尾是金句+留白,饭桌聊天不喊"一键三连"。

## 五、口语颗粒

提问者:"呀/嘛/啊"句尾高频;"那肯定…呀""岂不是…"。讲解者:"那我问你啊""没错""你不要忘了""说白了"。允许轻微的车轱辘话(真实对话的毛边),不许两个角色说话腔调一样——**腔调区分度是对话体的命**。
