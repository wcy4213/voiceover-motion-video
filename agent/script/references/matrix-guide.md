# 二维矩阵指南 · 类型 × 时长 → 怎么写

每次写财经口播前必读。先把选题落进下面四个格子之一,再按格子的打法和推荐风格动手。

## 四宫格总览

|  | **短视频(60-180 秒,约 1200-1800 字)** | **长视频(5 分钟+,约 3000-6000 字+)** |
|---|---|---|
| **金融热点** | 格子①:快讯锐评。一个事件 + 一条传导链 + 一句态度 | 格子②:热点深挖。事件全貌 + 多情景推演 / 来龙去脉 |
| **金融深度** | 格子③:一个知识点打透。一个概念/一个反常识切口 | 格子④:系统讲透。完整框架 / 全流程拆解 / 系列教学 |

下面逐格说明。

---

## 格子① 金融热点 × 短视频 —— 快讯锐评

**目标**:在事件发生的窗口期内,用最快节奏让观众"看懂这事+记住你的判断"。

- **推荐风格**:E 宏观时评(市场/数据/政策)、A 现象爆点(热点人物/公司/社会现象)。
- **字数节奏**:1200-1800 字。hook 占比要大(前 15-20 字必须是事件本身或反差)。只留**一条主传导链 + 一个核心判断**,不贪多。
- **骨架**:
  1. 事件钩子(直接抛刚发生的事 + 数字/反差)
  2. 一条传导链(为什么会这样,3-4 环讲清)
  3. 一个反转或追问(但真相是…/ 但要注意…)
  4. 一句态度收尾(E:盯什么信号;A:升华金句)
- **要点**:数据必须是**最新的**,务必 `web_search` 核实当日/当周数值与市场预期。短视频热点最忌信息过期。
- **反例**:别在 90 秒里塞三条传导链 + 五个数据,观众记不住。一条链讲透即可。

## 格子② 金融热点 × 长视频 —— 热点深挖

**目标**:热点事件的"全景解读",把短视频讲不下的多方博弈、来龙去脉、多情景全铺开。

- **推荐风格**:E 宏观时评(深度版,多情景推演)、A 现象爆点(人物/公司的完整故事线;若是讲金融史/商业人物/著名事件,用 A 的**金融叙事/人物传记变体**,见 style-A 进阶变体,对标饭统戴老板)。
- **字数节奏**:3000-6000 字。允许铺垫,但开头仍要有强 hook 把人留住。
- **骨架(E 深度版)**:事件钩子 → 完整传导链 → 提出真问题 → 乐观/中性/悲观三情景推演 → 关键变量+时间节点 → 落到各类资产的投教判断。
- **骨架(A 故事版)**:炸点 → 立靶 → 历史脉络/资本逻辑层层揭秘 → 反常识收割 → 升华。
- **要点**:长热点靠"层次"留人——双层风险框架(短期定方向+长期定高度)、多情景推演都是拉长且不松垮的好办法(见 style-E 进阶手法)。每一层都要有新数据/新角度,不能注水重复。

## 格子③ 金融深度 × 短视频 —— 一个知识点打透

**目标**:用一条短视频讲透**一个**概念、一个反常识规律、一个机制,让人"涨一个认知"。

- **推荐风格**:C 拆解科普(一个反常识切口拆到底)、D 框架投研(浓缩版,只讲一个工具/一条规律)。
- **字数节奏**:1200-1800 字。聚焦**单一知识点**,不铺全框架。用一个极简类比 + 一个例子讲透。
- **骨架**:
  1. 反常识切口(一个反直觉现象/惊人数字/一条铁律)
  2. 先破后立(大众以为是 A,其实是 B)
  3. 一层层拆 / 一个极简类比讲透机制
  4. 给一个干净的认知结论
- **要点**:深度短视频的关键是"克制"——一条视频只讲清一件事。比如不要一条里把 PE/PS/PB 全讲,只讲透"PEG 为什么能修正 PE"就够。极简类比(如"折现=10 年后给你 100 块你今天愿花多少")是把硬概念塞进短视频的利器。

## 格子④ 金融深度 × 长视频 —— 系统讲透

**目标**:把一套完整框架 / 一条完整产业链 / 一个完整周期 / 一个系列知识,系统讲到位,建立专业权威感。

- **推荐风格**:D 框架投研(完整框架+实战演示)、C 拆解科普(超长层层拆解)、B 知识体系(做成连续系列时;若是财报/期权/技术指标/经济学这类需系统开课的硬知识,用 B 的**硬核教学/课程化变体**,见 style-B 进阶变体,对标小雷大智慧)。讲一个国家经济/一个行业全景时,叠加 toolbox 的**"一口气了解 XX"全景框架法**(对标小Lin说)。
- **字数节奏**:3000-8000 字。可多模块、多案例、多层推导。
- **骨架(D 完整版)**:痛点钩子(学会能少走弯路)→ 引出框架并命名编号 → 逐模块四件套讲透(定义/逻辑/例子/局限)→ 模块联动成心智模型 → 真实案例跑一遍验证 → 升华+系列预告。
- **骨架(B 系列版)**:系列锚点+致谢 → 抛核心问题 → 唠家常铺垫 → 分点讲解 → 预告下期 → 固定人设签名。
- **要点**:长深度最考验"结构"。给框架命名编号(三把尺子/五个关键词/四阶段)、每个部件主动讲局限、最后联动收束,是建立信任和记忆的关键。案例数据务必真实可核查。

---

## 跨格子的通用原则

1. **类型决定"快还是深",时长决定"展开多少"**。同一选题在不同格子里是不同的稿子:别把深度长视频的框架硬塞进热点短视频,也别把热点短视频注水成长视频。
2. **风格服从格子,不是反过来**。先定格子,再从映射表取风格;同格子内若两种风格都行,按受众和账号人设选。
3. **短视频做减法,长视频做层次**。短的删到只剩一个核心点;长的靠多层结构(多情景/多模块/多案例)撑长且不松。
4. **热点拼时效,深度拼增量**。热点稿的数据必须最新(写前 `web_search`);深度稿要让观众"学到能复用的东西"。
5. **任何格子都不能省**:真实数据、口语感、一个认知转折、记得住的收尾、合规底线。

## 选格子的一句话自检

写之前问自己:"这条视频,是帮观众**快速看懂正在发生的事**(热点),还是帮他**学会一个长期有用的东西**(深度)?它要在**90 秒内打透一个点**(短),还是**几分钟里系统讲透**(长)?" 答完就知道进哪个格子、取哪个风格了。
