# 通用工具箱 · 财经口播跨范式技巧

不分范式都用得上的句式库、技巧和清单。写任何一套范式时都可来这里取料。

## 一、Hook 万能公式(前 3 秒决定完播率)

财经口播 hook 的本质:第一句话就给观众一个**停不下来的理由**。六种公式:

1. **反差对比**:把两个数字/对象拉到一起制造落差。"苹果十年 13 倍,英伟达十年 300 倍。"
2. **极端断言**:一句武断到想反驳的话。"贾跃亭是中国商界独一份的狠人。"
3. **悬念提问**:抛一个观众答不上来又想知道的问题。"明明美国油价更便宜,为什么美国人先活不下去了?"
4. **惊人数字**:一个反直觉的大数/小数。"携程净利率高达 53%,比茅台还能打。"
5. **关键词轰炸**:重复词制造情绪。"关停关停,全部关停。"
6. **冷知识反转**:一个颠覆认知的事实。"任天堂起家不是做游戏的,是开情侣酒店的。"

**禁用开头**:"今天我们来聊聊…""大家好,这期视频…""不知道大家有没有想过…"(平、慢、劝退)。

## 二、转折/钩子句式库(每 2-3 个论点抛一次)

让观众一次次被拽回来的"认知反转"标记词:

- 但万万没想到哈 / 但诡异的是 / 可现在再看哈
- 真相是 / 重点来了哈 / 最讽刺的名场面来了
- 其实不是这样的(先破后立)
- 那你肯定好奇 / 那么问题来了
- 多说一句哈(补料,显内行)

## 三、数据呈现技巧

- **逐年递进**:连续几年的数字排着读,制造增长冲击。"43.68 亿 → 297.6 亿 → 728.8 亿 → 1201 亿。"
- **换算参照系**:把大数字换成可感知的对象。"5.5 万亿美元 = 美国 GDP 的 16%。"
- **点名信源增信**:"社科院报告提到…""疾控中心数据显示…"
- **主动标注局限**:"注意,这是十年前的数据了。"(反而显真实可信)
- **算账可视化**(尤其智商税类):把成本一项项拆开摆给观众。

## 四、口语化改写清单(文章 → 口播)

写完先念一遍,按这个清单改:

- 加口头语:哈 / 呢 / 啊 / 那 / 咱们 / 你想啊
- 长句拆短:一句话超过 25 字就考虑断开
- 数字口语化:说"5.5 万亿美元",别写"5.5T";百分比直接读
- 书面词换大白话:"导致"→"结果";"然而"→"但是";"综上所述"→"所以说"
- 加"说人话就是…"给每个专业概念配一句翻译
- 删掉所有连接词堆砌(因此/从而/进而)

## 五、AI 味自查(必须避免)——已升级为专项手册

基础负面清单(出现即改写):
- 排比式空话:"不仅…而且…更是…"连用
- 总分总八股:"首先…其次…最后…综上"
- 万能升华:"在这个时代,我们每个人都…"
- 名词堆砌:"赋能/抓手/闭环/生态"扎堆
- em-dash 滥用(全篇 ≤3 个)
- 小标题用疑问句或名词短语 → 改成陈述句

> **重要:负面清单治标不治本。** AI 味的本源是"均匀 + 无人称 + 零冗余",光避开坏词没用。初稿写完后,**必须按 `anti-ai-flavor.md`(去 AI 味专项·毛边注入手册)做一遍毛边注入七法 + 终检三问**——句长破坏、把"我"放回去、护栏句、互动现挂、转场降级、密度故意不均、删总结句。该手册同时规定了 micro-techniques 各技巧的用量上限(每段满配=模具味)。

## 六、合规清单(RockFlow / 投资类账号)

- 不直接荐股、不给具体买卖点。
- 不诱导开户、不承诺收益。
- 敏感宏观话题(ADR 退市风险、关税、美联储鹰派)用"投资者教育 / 宏观解读"中性框架。
- 涉及具体投资品时主动加风险提示。
- 面向大陆受众的离岸券商内容,框架用"投教/解读"而非"操作建议"。

## 七、软广识别清单(整理选题/选参考时用)

判断一条财经视频是否软广(用于剔除参考样本或自查):

| 信号 | 说明 |
|---|---|
| 标题绑定品牌/型号 | 如"尚界 Z7 敢凭真实力""理想 i6""奔图科技" |
| 全片服务单一品牌 | 所有论证最终指向一个品牌的卖点 |
| 结尾落到购买理由 | "都浓缩在这辆 20 万级的车里""真正的壁垒" |
| 通篇只夸不破 | 没有任何批评/中立分析,只有正面背书 |
| 标签带广告话术 | #敢凭真实力 这类品牌 slogan 式 tag |
| 框架/科普式植入 | 用真方法论或真科普当外壳,但全片只用**一个**品牌做唯一案例,结尾导向"它就是你的理想答案"(如奇兵到家"五步法"、理想 i6"用钢"科普) |

> 对照:中立商业拆解(如携程模式、智商税揭穿)即使提到品牌也**不是**软广——它会拆缺点、给中立判断、不导向购买。区别在于**立场是否被单一品牌买断**。

## 八、"一口气了解 XX"全景框架法(对标 小Lin说)

当要在一条视频里讲透**一个国家经济 / 一个行业 / 一个大概念**(俄罗斯经济、元宇宙、人形机器人)时,用"一口气了解"式的全景框架,把庞杂信息压缩成几个有序的板块,让观众一条视频建立完整认知地图。

打法:
- **开头给"地图预告"**:"我们快速浏览一下 XX 的现状,你准备好了吗?" 先让观众知道这是一次系统扫描。
- **用固定维度切板块**:讲国家经济常用"地理人口 → 资源禀赋 → 产业结构 → 核心问题 → 未来";讲行业常用"是什么 → 谁在玩 → 怎么赚钱 → 有什么问题 → 趋势"。维度固定,信息再多也不乱。
- **每个板块一两个记忆锚点**:用一个最震撼的数字或事实代表这个板块("占地球陆地 1/8""核弹头最多但经济没存在感")。
- **节奏快、不恋战**:每个板块讲到位就走,靠"信息量大但有序"取胜,而不是深挖某一点。

适合长视频深度类(格子④),也可压缩成短视频"一分钟看懂 XX"(格子①/③)。

## 九、神类比库(把抽象金融概念讲具象,对标 小Lin说)

财经内容最难的是把抽象概念讲到小白能懂。一个好类比顶一段解释。可复用的类比思路:

- **利率 → 引力/油门刹车**:"利率对经济的影响,就像月球对地球——你感觉不到,但它决定潮汐。""降息是给经济踩油门,加息是踩刹车。"
- **折现 → 时间的打折**:"10 年后给你 100 块,你今天愿意花 100 买吗?不会,因为时间有成本。"(见 style-E 进阶手法)
- **成长股估值 → 镜子**:"成长股是利率的镜子。"
- **护城河 → 通用系统**:用"复印机里装了通用操作系统"讲平台型护城河。
- **CPU 调度 → 大管家**:用"大管家从仓库翻数据再分发"讲芯片协同。

- **通胀 vs 投资 → 跑步机**(阿泰):"钱贬值是跑步机的速度,投资是你在上面跑。收益率超过贬值速率才往前,低于就被甩出去。简单难度跑 CPI 的 2.15%,困难难度跑 M2 的 12.9%。"
- **资产分类 → 会不会下蛋的鹅**(阿泰):"存款债券股票会给利息分红,是会下蛋的鹅;黄金、拉布布、收藏品不产生现金流,是不会下蛋的鹅,赚钱只能赌下一个买家出更高价。股票是既下蛋又能长胖的鹅。"
- **另类资产判断 → 稀缺 × 价值共识 双坐标**(阿泰):"郁金香:不稀缺无共识,崩;黄金:极稀缺+全球硬共识,240 倍;我的自画像:稀缺但无共识;拉布布:共识在、稀缺的阀门在老板手里。"
- **通货膨胀 → 老母鸡和印钞机**(阿泰):"老母鸡下蛋的速度赶不上印钞机印钱的速度,同样的钱能换的蛋越来越少。"
- **存储芯片 → 收费站/过路费**(北大研哥):"台积电收制程费,英伟达收算力费,存储芯片收数据搬运的过路费。"

造类比的公式:**把陌生的金融概念,映射到观众日常生活里熟悉的、有相同结构的事物上**(踩油门、打折、引力、管家、跑步机、下蛋的鹅)。类比要"结构对得上",不能只图好玩而失真。
