# 范式 D · 框架投研型(对标:坤元财研)

> **矩阵归属**:金融深度类主用风格之一。短视频=格子③(浓缩成一个工具/规律)、长视频=格子④(完整框架+实战演示)。

适合**投研方法论、分析框架、产业链深度拆解、周期/估值模型**类选题。核心打法:全片围绕一套**可迁移的框架/工具**组织,案例只用来验证框架;信息密度高、逻辑链长,目标是让观众"学会一种能复用的分析能力",而非记住一个故事。这是四种范式里最硬核、最长(中长视频,4000-8000 字)、最适合建立专业权威感的一种。

## 与 C 型(阿泰拆解)的关键区别

C 型和 D 型都"先破后立、层层下钻",但定位不同:

| | C 拆解科普型 | D 框架投研型 |
|---|---|---|
| 核心交付 | 拆透**一个**对象(这家公司/这个智商税) | 教会**一套**可迁移框架(估值法/周期模型/分析法) |
| 案例作用 | 案例本身就是主角 | 案例是框架的**验证素材**,可替换 |
| 观众收获 | "原来这事是这样" | "我以后能自己分析同类问题" |
| 深度 | 中等,网感强 | 硬核,系统,投研味 |

> 一句话:C 型给你鱼,D 型给你渔。

## 节奏骨架(框架教学版)

```
1. 痛点钩子      抛一个"学会就能少走弯路"的能力承诺 / 一个反常识铁律
2. 引出框架      给出本期要交付的框架名称和它解决的问题(几把尺子/几个关键词/几个周期)
3. 逐模块拆解    框架的每个部件单独讲透:定义 → 公式/逻辑 → 例子 → 局限
4. 模块间联动    把各部件串成一个整体系统(估值三角 / 五步主线 / 周期四阶段)
5. 实战演示      用一个真实案例完整跑一遍框架,验证它管用
6. 升华+预告     提炼一条最重要的认知,常带系列预告("下期揭秘房地产周期")
```

## Hook 句式库(承诺一种"能力"或抛一条"铁律")

D 型 hook 不靠八卦张力,靠"学会它你能……"的能力承诺,或一条反直觉规律:

- **能力承诺**:"有没有一种方法,让你一眼判断一门生意是贵了还是便宜?"
- **少走弯路**:"拥有快速看懂一个行业的技能,无论择业创业还是投资,都能少走弯路。"
- **反常识铁律**:"揭秘一个反常识铁律:行业最危险时不是亏钱,而是业绩最火爆的时候。"
- **能力对照**:"看完你就能明白,这轮 AI 大基建到底有没有泡沫?"
- **上帝视角**:"本期帮你打开一个上帝视角,彻底看懂一个行业兴衰的顶层逻辑。"

## 框架的呈现技巧(D 型的核心竞争力)

1. **给框架起名字、给部件编号**。把抽象方法封装成可记忆的结构:"三把估值标尺 PE/PS/PB""需求、供给、利润、壁垒、周期五个关键词""复苏-繁荣-衰退-萧条四阶段"。编号和命名让观众有"拿到了一套工具"的获得感。

2. **每个部件四件套讲透**:定义 → 公式/底层逻辑 → 一个例子 → 局限/陷阱。例如讲 PB:定义(市值/净资产)→ 逻辑(做最坏打算)→ 例子(银行 PB<1、苹果 PB 56 倍)→ 陷阱(资产质量、无形资产被低估)。**主动讲局限是 D 型建立信任的关键**,显得客观不忽悠。

3. **用 AB 对比制造"反转"**。D 型的转折不靠情绪,靠逻辑反转:"A 公司 PE 50 倍,B 公司 30 倍,谁贵?"→ 引入增长率后"一年后 A 反而更便宜",由此自然引出 PEG。

4. **公式可视化推导**。把抽象关系拆给观众看:"市销率 = 净利率 × PE,所以云计算公司 20%×30 = 6 倍合理,超市 5%×15 = 0.75 倍合理。"用推导代替结论,让观众信服。

5. **联动收束**。最后把所有部件拼成一个整体心智模型:"PE 是起点、PS 压注潜力、PB 是最后防线,三者构成估值三角。"

## 实战演示段(用真案例验证框架)

D 型几乎都有一段"拿真实公司/真实数据跑一遍框架"的演示,这是把方法论落地的关键:

- 周期模型 → 用京奥科技固定资产+净利润+股价的真实数据,走完复苏到萧条全程。
- 行业框架 → 套到一个具体行业,逐个关键词填。
- 估值法 → 给假设公司算出合理股价。

> 演示用的数据必须真实、可核查。涉及具体公司财务数据时优先 `web_search` 核实,这是 D 型可信度的命门。

## 升华句库(提炼可迁移认知)

D 型收尾不煽情,而是提炼一条"带得走"的认知,常配系列预告:

- "市场永远交易的是预期而不是现实,股价的拐点永远领先于业绩的拐点。"
- "看懂一个行业,其实就是看懂谁赚谁的钱。"
- "评判高低的关键不在数字本身,而在你对终局的判断是否准确。"
- "成功的成长股投资,最终必然落地到 PE 估值的验证上。"
- 系列预告:"看懂了 10 年周期,那决定我们这代人命运的 20 年周期是什么?点关注,下期揭秘房地产周期。"

## 语气标记

理性、克制、有投研专业感,但靠类比把硬知识讲软:"你可以把 PE 理解成回本周期""算力就是这个时代的土地储备""CPU 就像个大管家"。第一人称会适度交代资历建立信任("近 10 年投研积累""我亲测了大模型能力"),但不浮夸。整体像一个**愿意把方法论倾囊相授的内行老师**。

## 软广识别提醒(重要)

D 型框架极易被做成**框架式软广**:用一套真方法论当外壳,但全片只用某一个品牌做唯一案例,结尾导向"它就是你的理想答案"。判断标准:
- 框架讲解是否客观,但案例是否**只有一个品牌**且无替代
- 结尾是否从"方法论"突然滑向"所以选 XX 就对了"
- 标签是否带具体品牌名

> 中立的框架教学(用多个或可替换案例验证、给案例挑缺点)是正常内容;若框架沦为单一品牌的垫脚石,就是软广。

## 一条完整样例的骨架(以"相对估值的底层逻辑"为例)

1. 痛点钩子:有没有方法一眼判断公司是贵是便宜?
2. 引出框架:三把尺子 PE / PS / PB
3. 逐模块:PE(→盈利收益率→PEG)、PS(=净利率×PE 推导)、PB(安全垫+陷阱)
4. 联动:三者构成"估值三角",从利润/成长/资产三条线定价
5. 实战:用 PEG=1 反推合理股价的演示
6. 升华+预告:估值聊完,下期再见
