# 风格 J · 美股财报/持仓快评(对标:呱呱蛙Investing)

> 财报季和 13F 披露季的**快评格式**:不带情绪、不喊单、纯数据驱动,但每组数据后面都跟一句"市场为什么这么反应"的解读。提炼自呱呱蛙 10 条真实稿(四巨头财报、英伟达、AMD、苹果财报;Leopold/桥水 13F 持仓解读;存储芯片行业拆解)。

## 一、定位与适用

- **格子**:金融热点 × 短/中视频(2-5 分钟,1000-2500 字;J0 前瞻为 60-100 秒)。**时效窗口最窄的格式**——财报前一天(T-1)、财报盘后 24 小时内、13F 披露后 1 周内。
- **选题**:① 财报前瞻(T-1,**流量主力**,见 J0);② 美股财报快评(单家或同日多家对比);③ 机构 13F 持仓解读(桥水、知名基金、明星个人);④ 一个行业的供需快拆(存储芯片)。
- **RockFlow 适配度:最高。** 美股财报季是 Bobby AI 用户的刚需场景;13F 数据 Craig 已有免费 API 栈(FMP/SEC),可做成财报季流水线。E 风格管宏观事件,J 风格管个股财报——两者拼起来正好盖住"金融热点"的高频日历。

## 二、与 E/H 的边界

| | E 宏观时评 | J 财报快评 | H 硬核教学 |
|---|---|---|---|
| 对象 | 宏观数据/央行/政策 | 个股财报/机构持仓 | 一份财报的**教学级**精读 |
| 长度 | 短 | 短-中 | 长(5 分钟+) |
| 态度 | 有倾向性判断 | 中性偏解释,"参考一下就好" | 教你自己会看 |

判定:讲"美联储议息"→E;讲"Meta 财报盘后跌 7%"→J;讲"手把手教你读懂英伟达财报每一项"→H。

## 三、节奏骨架

### 骨架 J0 · 财报前瞻(T-1,流量主力)

> 2026-07 双平台实测的机制证据:搜索需求集中在财报出来**之前**——T-1 条搜索占比 52%~77%,复盘条只剩 1.6%,搜索词是"XX财报""什么时候发""财报预测"。前瞻/复盘的**总流量**差距尚无定论(干净对照仅 1 组:谷歌小红书 8 倍;海力士抖音对是反例,复盘靠推荐页持平),但排产仍然 T-1 优先:只有它吃得到搜索,且无重复判定风险。证据分级与验证计划见 `platform-douyin-xhs.md` 铁律 1。财报季默认先排 J0,盘后快评 J1 做副条。

```
[硬信息开场]  第一句 = 标的 + 事件 + 一个硬数字,禁寒暄禁铺垫
            ("韩股连跌,市场把宝全押在海力士明晚这份财报上")
[给时间表]    明确几点发、盘前盘后——观众就在搜"什么时候发",
            这句话同时原样写进发布文案(标题 SEO)
[三个看点]    每个看点 = 一个带门槛数字的判断变量
            ("云增速能不能守住 60%""1800-1900 亿美元的 capex 是维持还是上修"),
            最多三个,多了记不住
[押注互动]    30 秒内抛情景选择("强财报止血 / 数字好指引平 / 利好出尽,你押哪种"),
            发布后写进置顶评论自己占一楼
[预告收尾]    cliffhanger + 具体关注理由
            ("出了结果我第一时间盘,周四英特尔那条讲隐含波动 15% 怎么读")
```

- **时长锁 60-100 秒(约 1200 字以内)。** 实测 1:19 的前瞻条平均播放占比 24.5%,全账号最好;3 分钟以上,25 秒之后的内容只有 4~6% 的人看到。
- **25 秒结算线**:时间表 + 最大看点必须在前 25 秒交付完。

### 骨架 J1 · 财报快评(单家/多家)
```
[极简开场]   "hello 大家好,今天 XX 发财报了,我们来看一下。"
            ——不做悬念 hook,受众是带着目的来的,直接上菜
            ★开场适配:这种冷开场只适用于搜索/粉丝向流量(带目的而来,
            实测搜索占比高的条 2s 跳出反而最低)。粉丝基数小、靠推荐页
            分发的账号,第一句改用 J0 式硬信息开场(标的+反差数字),
            否则 2s 跳出奔着 40% 去
[总览]       先给全景一句话:"四家营收基本都保持了接近 20% 的增长"
[反差切入]   ★招牌拍点:挑"数字最好但股价最差"(或反过来)的那家先讲——
            "Meta 营收增长 33%,但股价表现是财报后最差的,盘后跌了 7%"
[解释落差]   回答"为什么市场不买账/为什么超预期":落到资本支出、指引、
            利润率这些市场真正定价的变量上("营收里接近 60% 都投了资本支出,
            而且 Meta 的资本支出全是自己用,转移不出去")
[逐家过堂]   按"股价反应"排序逐个讲,每家 = 核心数字 ×2-3 + 一句市场逻辑;
            平庸的快速放过("微软亚马逊平平无奇,业绩依然优秀")
[收尾判断]   一句克制的总结 + 提示下一个观察点(下季指引/某条业务线)
```

### 骨架 J2 · 13F 持仓解读
```
[人物速写]   这是谁、什么来头、为什么最近火(2-3 句,带争议点更好)
[祛魅声明]   ★招牌拍点:先泼冷水修正大众误读——
            "传的一年翻 20 倍,部分可能来自外部资金流入,并不都是收益"
[持仓主线]   按仓位排名讲变化:加了什么、清了什么、和上季比动了哪里
[口径科普]   嵌入一段数据局限科普("13F 对期权只披露正股对应金额,
            不披露行权价和到期日,所以看不出真实成本")——这是增信的核心
[复盘打脸]   找一个"差点对了/彻底错过"的真实操作讲故事
            ("英特尔看涨期权拿了四个季度,涨三倍前一个季度全清了,倒在黎明前")
[收尾]       "不用太神话这位老哥,持仓大家参考一下就好。"
```

## 四、写作铁律

1. **数据密度全风格最高,但每个数字必须配"市场怎么读它"。** 报数→解读→报数→解读,严格交替。只报不解读=念财报,只解读不报数=空谈。
2. **绝不喊单。** 全篇唯一允许的立场词是"我估计/我觉得这个担忧是合理的"这种贴着数据的轻判断。收尾必须降温("参考一下就好")。这同时是 RockFlow 的合规姿势。
3. **主动讲数据口径的坑。** 13F 滞后 45 天、期权披露口径、汇率口径——每期至少讲一个。专业感和信任感全靠这个,也是和营销号最大的区分度。
4. **对比是骨,单点是肉。** 多家财报必须横向比(同样砸资本开支,为什么谷歌涨 Meta 跌);单家财报纵向比(和自家上季、和指引比)。
5. **平铺直叙是这个风格的美德。** 不用炸点 hook、不堆情绪词——快评的吸引力是"信息新鲜 + 判断克制",硬加 A 风格的爆点反而掉价。
6. **同一标的 J0→J1 双发时,J1 必须换角度、换首帧、换标题词。** 从"发生了什么"改成"XX 暴跌之后,下一个要盯的信号"。实测教训:谷歌复盘条与前一天前瞻条同题材、同款紫底首帧,被抖音判"重复发布"限流,只拿到 115 播放(前瞻条 8849)。对照组是没被限流的海力士复盘(4990 播放,推荐页托底 97.1%),但搜索占比只剩 1.6%、主页访问 0、涨粉 7——即便不限流,复盘的结构性天花板也在搜索和转化上。

## 五、口语颗粒

"hello 大家好""我们来看一下""那""比方说""不过呢这边还是要解释一下""可以说是""大家有兴趣也可以去看一下"。语气词密度低于 A/C,接近平静讲述——这是该风格的语域本体,不要往上加戏。
