# 范式 A · 现象爆点型(对标:小白学财经)

> **矩阵归属**:金融热点类主用风格之一(热点人物/公司/社会现象)。短视频=格子①、长视频=格子②(故事版)。

适合**热点公司/人物、社会经济现象、反差数据**类选题。核心打法:前 3 秒抛炸点,中段用资本视角/历史脉络/反差数据层层揭秘,结尾升华一句记得住的金句。单条约 1200-1800 字,短视频形态。

## 节奏骨架(6 拍)

```
1. 炸点 HOOK     (开头 1-2 句)   反差数字 / 极端断言 / 悬念提问
2. 立靶          (3-5 句)        交代现象规模,抛出"今天聊聊…"
3. 数据夯实       (1-2 段)        用一连串真实数字把现象砸实
4. 揭秘转折       (核心,1-3 段)   "真相是…""背后是…" 揭露资本/制度/历史逻辑
5. 反常识收割      (1 段)          补一个反直觉的点,再拽一次注意力
6. 升华金句       (结尾 1-2 句)    上升到时代/人性/资本层面收口
```

## Hook 句式库(前 3 秒最关键)

这套账号的 hook 几乎全是"反差 + 数字"或"极端断言":

- **双线反差**:"这是苹果的走势,十年 13 倍;这是英伟达的走势,十年 300 倍。"
- **极端断言起手**:"美国人到底有多胖,真相大家绝对想不到。"
- **关键词轰炸**:"关停关停,全部关停。"/"热热热热热,真的太热了。"
- **悬念提问**:"明明美国油价比中国便宜,为什么更有钱的美国人却先受不了了?"
- **狠人定性**:"在中国商界,贾跃亭绝对是独一份的狠人,也是最离谱的存在。"
- **打赌挑衅**:"一个视频了解中石油中石化,我打赌 99% 的人都搞不清。"
- **巨额数字砸脸**:"人类历史上最大规模的财富转移来了,2026 年人均年终奖 300 万元。"

> Hook 原则:第一句话里要么有一个让人意外的数字,要么有一个让人想反驳/想知道答案的断言。绝不要用"今天我们来聊聊…"开头。

## 中段揭秘的常用框架

财经爆点视频的"揭秘"通常落到这几类底层逻辑之一:

- **资本阴谋视角**:谁在背后赚钱?(如美国肥胖 → 玉米糖浆 + 食品资本 + 医疗资本"两头收割")
- **历史脉络视角**:从创立到今天的关键拐点(如英伟达 1993 创立 → 1999 发明 GPU → 2006 押注 CUDA → 2022 爆发)
- **时代变迁视角**:用前后数据对比说明"时代变了"(如客运站关停 vs 大巴复活;啃老现象背后的财富增速断崖)
- **制度/政策视角**:政策如何改写格局(如土地财政终结、人口数据背后的区域格局)

## 数据呈现技巧

- **逐年递进砸数字**(制造冲击力):"2022 年净利润 43.68 亿,2023 年 297.6 亿,2024 年 728.8 亿,2025 年 1201 亿美元。"
- **换算成可感知的参照系**:"5.5 万亿美元,相当于美国 GDP 的 16%、中国的 25%。"
- **数据来源点名增信**:"中国老龄科研中心发布过一个数据…""社科院调研报告提到…"
- **主动标注数据局限**(反而显真实):"注意啊,这是十年前的数据了。"

## 转折句式库

- "但万万没想到哈…"
- "但诡异的是…"
- "最讽刺的名场面来了…"
- "真相是呢,既…"
- "可现在再看哈,却是…"
- "重点来了哈…"

## 收尾金句库(升华是这套账号的标志)

收尾几乎都上升到时代/人性/资本层面,句式偏书面、有排比感:

- "时代不同了。"(短促有力,先抑后扬)
- "一代人托举一代人向上,就跟实现中华民族伟大复兴一样,需要一代又一代人的努力和拼搏。"
- "如今的英伟达手握全球 AI 时代的底层命脉,正在用算力重新计算世界,用科技重新定义世界规则。"
- "在资本眼里,只有赚钱这一件事。"
- "时代从不会淘汰谁,路人只会不断更新更适配大众的生活方式。"

## 语气标记

口头语高频:"哈""呢""啊""那""咱们""大家有没有发现""多说一句哈""说人话就是…"。整体语气是**带情绪的讲述者**——有态度但留分寸,常自我设限("今天这个视频不是指责谁")以避免冒犯。

## 一条完整样例的骨架(以"英伟达为何那么值钱"为例)

1. 炸点:苹果十年 13 倍 vs 英伟达十年 300 倍
2. 立靶:5.5 万亿市值=美国 GDP 16%,今天聊它怎么炼成的
3. 数据夯实 + 历史:1993 创立 → 失败差点破产 → 1999 发明 GPU → 上市
4. 揭秘转折:2006 押注 CUDA 是命运拐点,用"复印机装通用系统"打比方讲清护城河
5. 反常识收割:CUDA 曾是烧钱机器,2015 黄仁勋一度觉得要破产,直到 2022 爆发
6. 升华:用算力重新计算世界

## 进阶变体:金融叙事 / 人物传记型(对标 饭统戴老板)

当选题是**一段金融史、一个商业人物、一场著名事件**(327 国债事件、曹德旺、马斯克、Palantir 发战争财),可以把 A 型升级成"长篇叙事版"——用讲故事的方式还原事件,用人物命运牵动情绪。这是抖音头部财经叙事的打法,适合 3000-6000 字的长视频。

### 叙事型的独特手法

1. **命运感悬念开头**。不只抛炸点,而是抛一个"勾着你想知道结局"的命运钩子:
   - "这是中国金融史上最邪门的一场赌局,赢的人一个接一个离奇死去,输的人却近 80 岁善终。"
   - "跳楼、枪毙、入狱、逃亡和死刑——这就是当年那些赢家的人生下场。"
   - "捐了最多的钱,却挨了最狠的骂,你猜这是谁?"

2. **数字暴击 + 人物体验绑定**。把冷数字翻译成人的极端体验:
   - "一天亏掉 16 个亿是一种什么样的体验?"
   - "哈梅内伊被刺杀,Palantir 市值一天暴增 200 亿美元。"

3. **戏剧化叙事节奏**。像讲故事一样有起承转合:埋伏笔→冲突升级→失控→结局。常用"层层加码,节节攀升,步步失控""玩大了,玩脱了,破罐子破摔"这种递进短句推进张力。

4. **多集连载运营**。一个大事件可拆成多条:正片 + 完整版 + "核心人物历史结局盘点"。把一个 IP 选题做深做长。

5. **人物弧光 + 时代背景**。把个人命运放进大时代里,讲出"宿命感"——人物的成败不只是个人选择,也是时代和资本的产物。

### 叙事型骨架(7 拍)

```
1. 命运钩子      抛出耸动的结局/反差,勾住"想知道为什么"
2. 人物/事件登场  介绍主角和他所处的时代背景
3. 起势          主角如何起家/事件如何开局(埋下伏笔)
4. 冲突升级       矛盾、赌局、危机一步步加码(张力拉满)
5. 失控/高潮      事件走向不可收拾的顶点(数字暴击)
6. 结局          人物下场/事件落幕(命运感收束)
7. 升华          从这段故事提炼一条关于人性/资本/时代的金句
```

### 叙事型与基础 A 型的区别

基础 A 型是"现象揭秘"(讲清一个现象背后的逻辑);叙事型是"故事还原"(用人物命运和戏剧节奏讲一段史)。叙事型更长、更重情节、更靠悬念和人物弧光留人,但底层仍是 A 型的"反差 hook + 数据 + 反转 + 升华"。

> 合规提醒:涉及真实人物(尤其在世商业人物)做传记叙事时,只陈述有公开来源的事实,不编造情节、不做诽谤性定性;评价两极的人物(如曹德旺)要呈现两面,不替观众下道德结论。涉及历史事件保持中性还原。

## 进阶变体 A2:硬科技产业热点型(对标 北大研哥)

当热点是**硬科技/产业链事件**(国产芯片突破、某金属暴涨卡住 AI、存储芯片三巨头破万亿、光纤争夺战、巨头收费/降价),用 A2 变体——底层仍是 A 的"炸点→揭秘→升华",但揭秘层换成**产业链拆解**,升华层换成**国产替代/国家产业叙事**。短-中视频(1500-2500 字)。提炼自北大研哥 9 条真实稿(2 条软广已剔除)。

### A2 的独特手法

1. **固定人设签名贯穿**。开场立靶处和结尾各扣一次口头禅:"新闻看热闹,严哥看门道""关注我,看懂经济科技与国家发展"。RockFlow 用时换成自己账号的等价签名——**签名句是指纹,必须有,内容自定**。
2. **三问立靶**。炸点之后,固定用三个递进问题立住本期范围:"今天咱们就聊聊 ① 它到底怎么造出来的 ② 国产走到了哪一步 ③ 这对中国 XX 行业意味着什么"。观众 10 秒内知道这条视频的获得感清单。
3. **认知纠偏起手**。揭秘第一步常是纠正一个大众误判:"可能有人会说,4 纳米有什么稀奇的,手机芯片都 3 纳米了?这其实是认知偏差——车规级和消费级完全是两个赛道"(寿命 15 年 vs 2-3 年、零下 40 到 150 度、ASIL-D)。先破再立,专业感立住。
4. **产业链收费站类比**。把竞争格局翻译成"谁在哪个环节收什么钱":"台积电收制程费,英伟达收算力费,存储芯片收的是数据搬运的过路费。"一句话讲清商业模式位次。
5. **主动护栏 + 克制**。讲敏感推断必加护栏句("官方没公布代工厂,行业惯例有保密条款;普遍认为是台积电,但这是猜测啊,并不确定");讲国产突破也主动泼冷水("自有晶圆厂目前能做的还只是 28/40/55 纳米,4 纳米还要靠外部代工")。**先认差距再讲突破**,可信度和情绪价值都拿到。
6. **双线对照**。常用"同一个坑,两种命运"结构:耐克 vs 阿迪(同被抵制,一个 11 季连增一个 7 季连跌)、三星退出中国 vs 海信坐上主桌。对照即叙事。

### A2 骨架(7 拍)

```
1. 炸点          一个产业级数字/事件("42 万一吨,半年暴涨 40%""存储疯了,这时候一定要冷静")
2. 签名立靶      口头禅 + 三问清单
3. 认知纠偏      先纠正大众的第一直觉("你以为 X,其实是两个赛道")
4. 产业链拆解    供给端/需求端各 1-2 段,数字+护栏句;谁卡住谁、谁是收费站
5. 中国位置      国产现状:先认差距,再讲突破,给真实进度条
6. 判断信号      "我认为最重要的信号是…"(挂在第一人称上的判断)
7. 签名收尾      一句产业叙事升华 + 固定签名 + 评论区留白
```

### A2 合规提醒(RockFlow 场景)

国产替代/中美科技叙事流量高但情绪重:数据必须可溯源;不渲染对抗情绪,落点放在"产业逻辑和投资视角";A 股/美股标的只做产业链位置分析,不荐股。语料:`corpus/A2-beidayange.md`。
