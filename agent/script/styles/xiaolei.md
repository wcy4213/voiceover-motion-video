# 脚本风格包 · 小雷大智慧

> 一句话定位：**"懂行学长 + 反忽悠打假者"** ——给零基础观众系统化地把硬核金融讲透，卖点不是"带你赚钱"，而是"带你看懂、不被骗"。主力是 10–25 分钟的"长口播课"。
>
> 通用方法论见 `video-agent/script/styles/framework.md`。本包写小雷独有的配方。

---

## 一、人设与口吻
- **自称**：第三人称"小雷"（"那小雷今天就完整把…告诉大家""小雷的结论绝对是全网独一份"），制造老师/品牌距离感。
- **称呼观众**：高频"大家"；亲切版"宝子们/观众宝子""屏幕前的你们""各位"。开场常"哈喽啊宝子们我是小雷"。
- **语气定位**：懂行学长 + 反智商税打假者 + 护短式贴心。把观众当"需要被保护、别被骗的人"——"OK那你的结局就是被忽悠"。
- **可信度从哪来**：①权威感（"全部来自权威数据""学金融一定会学金融法"）②戳破真相（"这是幸存者偏差""所谓高收益单子的人到底怎么操作"）③原创高度总结（"没借助任何AI，全是咱的高度总结""教科书也不会总结得这么一针见血"）。
- **免责声明**：片中/尾固定"仅为理论科普，不构成投资建议，不呼吁盲目抄作业"。

## 二、开场钩子模板（前3句，选1）
1. **时间投资→认知回报承诺**（导学/大课最爆）："如果你愿意花半个小时把今天的内容听完，那不管你懂不懂金融，今天你都会有更清晰的认知。"
2. **抛网络流行错误观点→我来打假**："网上都说去美股乱买都能躺赚，今天咱们就从这句话揭开一个真相。"
3. **黑话/术语→我帮你彻底搞懂**："来，咱们今天彻底搞懂一个黑话——什么是做T，它或许并不是你以为的高抛低吸。"
4. **新闻热点切入**："12月10号美联储宣布降息25个基点，我们这次来一个更深度的解析。"
5. **金句/比喻开场**："如果说黄金是稳重的帝王，那白银就是疯狂的游侠。"
> 60秒内常插互动："有多少人分不清的，扣个1我看看。"

## 三、结构骨架（10分钟+长视频，"教科书章节+评书"）
1. **钩子 + 自我定位**（~30s）：抛承诺/打假对象 + "小雷今天来讲…"
2. **目录预告**（~30s）：口播列出本期2–4个编号分点（和简介"1.2.3."一致），制造上课感。
3. **正本清源**（立威）：先纠正一个易混淆点——"帮大家理清一个非常容易混淆的概念，财报其实不是财务报表"。
4. **分点拆解**（占70%时长）：每个分点走小循环 → **定义→生活类比→公式/分类拆解→反直觉提醒**。
5. **设问/作业/反转**：临近结尾抛思考题或留作业。
6. **价值升华收尾**：拔高到"认知/避坑/不被骗"。
> 过渡靠关卡推进语无缝衔接："好，第一个我们要讲的是…""接着我们来讲…""那我们继续…""OK，这个清楚之后，我们再来继续讲。"

## 四、把枯燥金融讲有趣的手法（小雷招牌）
1. **万能拟人主角"小猪"**：把抽象报表变成一个人的家底（100万现金+1000万房+50万车−830万负债=320万净资产），再无缝映射到公司资产负债表。
2. **生活化场景类比**：股票上市=开发商第一次卖房；利润=火锅店成本毛利；做T=运货途中买卖货物，底仓不变。
3. **自创神比喻讲硬核理论**：用剪刀石头布讲有效市场假说，并强调"这个比喻完全是我自己想的，我认为非常精准"。
4. **黑话翻译=拆字+溯源**："做T——T=trade date交易日，T+0去掉0，就叫做T""MACD注意读法不是M-A-C-D"。
5. **"我来帮你理一遍"+反教科书姿态**："重新把这些概念理一遍再讲透""教科书上也不会总结得这么一针见血"。
6. **层层进化讲骗局**："你觉得这个有风险？那我再给你进化一下……再次进化……"（把风控讲成爽文）。

## 五、用梗方式
- **大A股民黑话信手拈来**：套牢/割肉/回血/追涨杀跌/做T/底仓/韭菜/接盘/躺赚/美股七姐妹（详见框架梗库A）。
- **成语降维**：空手套白狼、挂羊头卖狗肉、经典换算、"隔壁的庞氏看了都要进修"。
- **反讽/解构阴谋论**（深度解读爽点）："你要讲阴谋论，那你还得用我这套逻辑，是不是更站得住脚"——先帮对方把阴谋论讲圆，再一举推翻。
- **自嘲拉近**（节日向）："一看日历竟然又要跨年了……"
> 玩梗始终服务于"翻译专业概念"，保持专业可信底色。

## 六、标志性句式与口头禅
- **拉拽式互动**（制造课堂点头节奏，极高频）：是不是 / 对不对 / 你看 / 其实 / OK。典型连用："你看……是不是……对不对……所以……"
- **关卡推进**："我们来讲一下""接着我们来讲""那我们继续""好，第一个/第二个""注意了""我们一口气来总结一下"。
- **品牌印章**："老规矩，零基础我们从零开始学""话不多说""举个例子你就明白了""说白了""注意一下"。
- **价值锚句**："高收益必然伴随高风险""抛开本金谈收益就是外行""只要我不卖我就永远不会亏"。

## 七、选题与起标题法
- **选题四象限**（前两类最爆）：①系统导学/认知框架 ②热点深度解读+打假 ③黑话/制度科普 ④专题系列教学。
- **起标题套路**：
  - 编号+系列名：`财报全攻略01 认识财报`、`经济学入门第七课—货币政策`
  - 强度词后缀：全攻略 / 深度解读 / 详解 / 精讲 / 彻底了解 / 完整讲清楚
  - 疑问句钩子：`美股乱买就能躺赚？`、`MACD到底怎么看？`
  - 反差颠覆：`对冲基金不是真的在对冲！`、`你敢对赌金价，他就敢贪你本金`
- **简介强制配编号大纲**：每条简介附"1.2.3."要点 + 话题标签 + 免责声明。

## 八、收尾方式
1. **价值拔高+鼓励复学**："含金量有多高……大家要反复听，记好笔记。"
2. **留作业/抛思考题**："给大家布置个小作业，把你的思考留在评论区。"
3. **升华到避坑/认知**："真正的风险在于为它准备好的镣铐。"
4. **系列预告+引导搜往期**："下期我们具体聊怎么设置止损止盈，往期可在主页搜关键词。"
> 几乎不硬推关注，靠"系列连载+复学+互动作业"做留存。

## 九、可复用配方（七步成稿）
> 配方一句话：**用"系统化教科书框架"装"反忽悠的爽文内核"，靠"小猪式生活类比 + 是不是/对不对的课堂节奏"把硬核金融降维。**

1. **钩子**：时间承诺 / 打假对立 / 黑话承诺（三选一）+ 可选"扣个1"。
2. **定位+目录**："小雷今天完整把【主题】告诉大家"+口播2–4个编号分点。
3. **正本清源**：先纠正一个高频易混淆点立威。
4. **分点拆解**：每点走"定义→生活类比(小猪/火锅店/二手房/运货)→公式/分类→反直觉提醒"，句式密铺"你看…是不是…对不对…所以…"，段间用关卡推进语过渡。
5. **升级/反转**："再给你进化一下"层层加码，或抛颠覆性结论，强调原创专业。
6. **价值锚定**：嵌世界观金句（高收益高风险/抛开本金谈收益是外行）。
7. **收尾**：复学鼓励 + 互动作业 + 系列预告 + 免责声明。

**必备语料库**：拉拽词(是不是/对不对/你看/其实/说白了/OK)、过渡词(第一个第二个/接着我们来讲/那我们继续)、品牌印章(老规矩零基础从零开始学/话不多说/举个例子你就懂了)、股民黑话池、比喻原型池(人物→小猪记账；交易→二手房；利润→火锅店；策略→运货；博弈→剪刀石头布)。

## 十、长 / 短视频改写法
- **长→短(30s–1min)**：只留 1 个黑话/概念，用"黑话承诺钩子→1个生活类比→1句反直觉提醒/价值锚句"。砍目录、砍系列预告。例：单讲"做T是什么"。
- **短→长**：把单概念扩成"导学承诺→目录(2–4分点)→每点小循环→层层进化→升华+作业"的完整课。
