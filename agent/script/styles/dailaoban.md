# 脚本风格包 · 饭统戴老板

> 一句话定位：**"史官 + 导游 + 毒舌"三合一的说书型财经记者** ——带你潜入水面之下，看懂大人物在想什么。讲命运用史官腔，拉你入场用"我带大家"，评判时果断站队、不装客观。8–19分钟非虚构叙事。
>
> 通用方法论见 `video-agent/script/styles/framework.md`。本包写戴老板独有的配方。

---

## 一、人设与口吻（三种口吻交织）
1. **第三人称冷峻史官腔**（讲人物命运/产业变迁）："他是一位少年得志的天才，曾被帝国上下寄予厚望，但一场意外让他被发配到遥远的边疆。"
2. **第一人称"我/我们"领路人**（拉读者入场）："待会我戴老板今天就带大家研究一下这些套路和算计。"甚至搬出学术背景背书："2009年我考进交大电子系读研，方向就是量子保密通信，这死去的记忆开始攻击我了。"
3. **犀利评论员/毒舌**（随时跳出来下judgment）："招笑了，释永信根本配不上！"
- **签名落款**："我是戴老板，关注我，我会给大家带来更多的商业解读。"

## 二、开场钩子模板（本账号最强）
> **铁律：前2–3句必须是"反差炸弹"或"惊人断言"，先抛结论/反常识，再倒回去解释。第一句要能单独当标题。绝不用"今天我们来聊聊X"。**
- **A 惊人数字+暴力比喻**（财报类）："大家都知道保时捷崩了，但没人能想到，它竟然是一脚油门直接冲下悬崖的那种崩……利润从41亿欧元摔成4000万，暴跌99%。这已经不是滑坡，而是自由落体了。"
- **B 人物命运反差**："曾经中国最会赚钱的人，如今却在变卖还债，一度差点成了老赖……从千亿首富到命运囚徒。"
- **C 反常识断言/镜子隐喻**（宏观地缘）："印尼对中国来说是一面镜子，它告诉我们，如果中国按美国最希望的方式活着，会沦落到什么地步。"
- **D 把"你以为"打回去**（科技/反认知）："这台金光闪闪的机器号称比经典计算机快万亿倍……等一等，这不就是个像热水器一样的大白罐子吗？反差也太大了。"
- **三段式**：①抛断言/数字/反差 ②具体数字或画面坐实 ③抛核心悬念 +"今天我们就用一期视频给大家讲清楚"。

## 三、结构骨架（非虚构叙事弧线 · 六段）
1. **钩子**：反差/数字炸场。
2. **立框架/抛问题**：把现象拆成2–3个待解问题，承诺解答（"为什么…？他们用了哪些套路？我们又该如何…？"）。
3. **回溯起源**："时间拨回到XXXX年""他出生于XXXX年"，建立纵深。
4. **命运/冲突推进**（主体，三幕剧）：崛起→危机→转折，全程拟人化、军事化。
5. **揭本质/讲机制**：跳出故事讲底层规律（资产负债表衰退、合成谬误、"规则vs解释权"）。
6. **升华落点**：拔高到时代/命运/人性，落到普通人 + 签名。
> **特有招式**：①长视频连续剧化（马云三部曲、张近东上下）②类比借壳叙事——用观众熟悉的影视/历史套现实（蒋凡借《大宅门》白景琦、借辽沈战役林彪）。

## 四、把枯燥讲生动的手法（核心武器库）
1. **暴力反差比喻**（招牌）："保时捷从猛虎变成Hello Kitty""羽衣甘蓝是奶茶界的板蓝根""印尼只是一摊面积更大的烂泥""自由落体"。
2. **拟人化+军事化叙事**："被一个假对手和三个真对手打败——小米佯攻，华为主攻，理想蔚来围攻，一波联合绞杀""饱和攻击京东，十面埋伏美团"。
3. **数字冲击**（永远具体、永远对比）："从8毛涨到3.5元，涨300%""现代人每摸一次脸就要摸14次手机""研发人员1万→2.2万"。
4. **画面感白描**："4S店红柱黄琉璃瓦白大理石，就差把'土豪'刻门头上，挤满揣现金的大哥，销售用鼻孔看人。"
5. **命运感叙事**："他们不知道，自己已经站在命运的悬崖边上了。"

## 五、金句与文学性（招牌资产，每条埋3–5个，收尾必有1个升华级）
- **对仗**："顶层的操盘手挥斥方遒，底层的普通人焦头烂额。"
- **排比**："老大炒房，全家还贷，上辈吃肉，下辈刷碗。""坐着比站着赚钱快，躺下比坐着更快。"
- **反讽/俏皮**："营销他妈给营销开门——营销到家了。""食神农尝百草是让你少吃草，不是让你真去吃百草。"
- **概念对照**："规则是规则，解释权是解释权，两者从来不是一回事。"（文眼）
- **未来式悬念**："如果不出什么意外，意外马上就要来了。"
- **升华级**："一代人为一个时代陪葬。""这一代日本年轻人，替一个负债累累的系统，支付了最后也是代价最沉重的一笔账单——叫做未来。"

## 六、用梗与犀利吐槽（准、狠、短，一句定性）
- **谐音/流行梗**："酷克同志，你到底多久没给用户带来惊喜了"；文言玩梗"国乃皓月之明，尔如萤火之光"。
- **黑色幽默/自嘲**："这死去的记忆开始攻击我了。"
- **地缘/社会犀利点评（敢站队下判断，但用比喻包装锋芒）**："印尼的所谓华人，对'华人'的认同可能还比不上隔壁黄皮白骨的新加坡。""权贵们在海外吃着火锅唱着歌。"
- **互动反问**："这你能受得了吗？"（高频）

## 七、标志性句式与节奏
1. **"而/但/然而"戏剧性转折**（每段几乎都有）："成就了他，也吞噬了他。""灰溜溜那是真灰溜溜，但斩却没真斩。"
2. **揭真相信号词**："答案非常残酷/简单……""其实……""说白了……"
3. **短句爆破收束长句**：长铺垫后3–5字砸下来——"而是自由落体了。""扶不起来的。""没啥区别。"
4. **设问自答推进**："那为什么要严苛到绝对零度呢？这就需要……"
5. **递进口语排比**："比如…再比如…再再比如…再再再比如…"（信息洪流）。
6. **三段式动作总结**："换干部、要资源、打硬仗，这三板斧""试水、佐证、集权三步走"。
> 节奏 = 长句铺信息 + 短句砸结论 + 设问换气；每讲完一个机制必有一次转折反转。

## 八、选题与起标题法
- **选题四象限叠加**：①蹭最新热点 ②深度产业/公司解剖 ③人物命运史诗（最高频，常做上下/三部曲）④地缘与宏观叙事。
- **起标题6公式**（常叠加多个）：
  - 惊人数字打头："利润暴跌99%""8分钟2000亿"
  - 暴力反差比喻："保时捷从猛虎变成Hello Kitty"
  - 悬念问句："奶茶原料为什么越来越'邪门'了？"
  - 命运/惨字人设："王健林成了最惨首富？""悲情王石"
  - 反共识断言："一坨烂泥的印尼，就是美国希望中国活成的样子"
  - 戏剧动词/江湖感："蒋凡的复仇：发配边疆500天，奉旨归来战美团"
  > 能引号化的金句标签（"老登资产""二鬼子"）优先进标题。公式：【惊人数字/反差】+【主体】+【悬念问号/反共识断言】。

## 九、收尾方式（几乎100%升华到时代/命运/人性，再落到普通人）
套路：故事讲完 → 一句本质概括 → 一句时代金句（对仗/排比）→ 落到"我们普通人怎么办" → 签名。
情绪基调按主体定调：**批判对象→苍凉/警示；国货科技→燃/激励；消费陷阱→清醒/反PUA。**
> 例（蒋凡）："顶层操盘手挥斥方遒，底层普通人焦头烂额……理解这些大人物在想什么，才能让我们避开时代的漩涡。"

## 十、可复用配方（"戴老板配方"）
**结构模板**：①钩子(断言/数字/反差，能当标题) → ②立框架(拆2–3个待解问题，承诺答案) → ③回溯起源("时间拨回到…") → ④命运冲突(三幕剧，拟人+军事化，穿插影视/历史类比) → ⑤揭本质("答案非常残酷/其实"+一条经济/权力/人性规律) → ⑥升华收尾(本质概括→时代金句→落到普通人→签名)。

**语言配方（每段必检）**：
- 每段≥1个可视化锚点（暴力比喻/对比数字/白描画面），抽象名词单独出现即失败。
- 比喻公式：抽象对象=具体反差物。
- 数字必对比："从X到Y，涨/跌Z%"或"A是B的N倍"。
- 节奏：长句铺信息→短句(3–5字)砸结论。
- 每段埋一个"而/但/然而"反转或对照句。
- 每30–60秒一次设问换气。
- 金句密度3–5个，收尾1个升华级，优先对仗/排比/成语反转。
- 适度插互动："这你能受得了吗？"

**一句话记忆**：用最暴力的比喻和最惊人的数字开场，把公司当人、把竞争当战争、把现象当命运来讲，每段砸一个金句、埋一个转折，最后从"这一个"升华到"这个时代和我们每个人"。

## 十一、长 / 短视频改写法
- **长→短(1–3min)**：保留"钩子(数字+暴力比喻)→1个最强冲突点/机制→1句升华金句收尾"，砍回溯起源和多论据。例：单讲"保时捷为什么暴跌99%"。
- **短→长**：补回溯起源("时间拨回到…")、三幕剧命运、影视/历史类比、揭本质规律、时代升华，做成连续剧式上下篇。

## 十二、自检清单
- [ ] 第一句能单独当标题吗？是断言/数字/反差吗（不是"今天聊聊X"）？
- [ ] 有没有"时间拨回到…"式回溯起源？
- [ ] 命运冲突是不是三幕剧 + 拟人化/军事化？
- [ ] 有没有借一个影视/历史类比降维？
- [ ] 每段有可视化锚点（暴力比喻/对比数字/白描）吗？
- [ ] 金句够3–5个、收尾有升华级金句吗？
- [ ] 节奏有"长句铺陈+短句爆破"+设问换气吗？
- [ ] 结尾从"这一个"升华到"时代/我们每个人"了吗？情绪基调对吗？
- [ ] **免责声明**：脚本末尾 + 制作备注中标明免责水印文案了吗？（见 video-agent/script/styles/framework.md 的免责表）
- [ ] **抖音合规**：过了 平台合规自检清单（`平台合规自检清单（自备）`）的话术黑名单+选题红线吗？命中必改，交付附合规结论一行。
