# 财经视频脚本写作 · 通用框架

这是一套把**枯燥的金融、商业、科技、宏观内容**写成**好看、好懂、想转发**的口播脚本的方法论 + 风格调度中心。

底层素材来自对三个头部抖音账号全部口播转写的逆向拆解。本skill是"通用配方"；每个账号的"私房菜配方"在各自的风格包skill里。

---

## 一、先决定三件事（开工前必问/必判断）

写任何脚本前，先锁定这三个变量。如果用户没说，用合理默认值并在开头说明：

| 变量 | 选项 | 默认 |
|---|---|---|
| **风格** | 小雷 / 小Lin / 戴老板 / 用户自定义 / 混合 | 问用户；说不清就按选题匹配（见下表） |
| **长短** | 短视频(30s–2min) / 中视频(3–6min) / 长视频(8min+) | 看选题体量，财经故事默认长，单点科普默认短 |
| **平台/目的** | 抖音涨粉 / 知识付费导流 / 品牌 / 纯科普 | 抖音 |

**选题→风格的快速匹配：**
- 教"怎么看懂X"（财报、指标、制度、黑话）→ **小雷**（教学体）
- 讲"一家公司/一个国家的来龙去脉"、商战、宏观经济史 → **小Lin**（故事体）
- 讲"一个人物的兴衰/一个行业的命运/一个地缘真相"，要犀利金句和情绪 → **戴老板**（非虚构叙事体）

## 三、通用方法论（三种风格共享的底层技术）

不管哪种风格，把财经讲好看都靠下面这套通用武器。详细技法与例句见 `references/making-finance-fun.md`。这里是必须刻进肌肉的核心：

### 1. 钩子：前3句定生死
观众0.5秒就划走。开头**禁止**"今天我们来聊聊X""大家好我是XX"。必须三选一：
- **认知反转**："你以为它是X，其实它是Y"（麦当劳其实是地产公司）
- **惊人数字/反差**："利润暴跌99%，从猛虎变成Hello Kitty"
- **利益/好奇承诺**："花5分钟看完，你对X会有异于常人的认知"

口诀：**第一句要能单独拿去当标题。**

### 2. 结构：给观众一张"地图"
人会在"不知道还要听多久/听这个干嘛"时划走。所以：
- **早早给框架**："这里有两个支柱/三个原因，先看第一个……"（编号让人有进度感）
- **设问驱动**：每推进一步先替观众问出问题，问题就是路标。
- **详略由戏剧性决定，不由重要性决定**：背景"一丢丢带过"，冲突点慢慢讲。

### 3. 把抽象变具体（最核心的能力）
抽象名词单独出现 = 失败。每个概念必须挂一个"锚点"，四选一：
- **类比/打比方**：做空=借邻居的奶茶店股票卖掉再低价买回；储备猪肉=猪肉的中央银行
- **拟人化**：把公司/国家当人写（"日本经济很拧巴""阿尔诺上演逼宫大戏"）
- **数字具象化**：永远做对比——"从8毛涨到3.5元，涨300%""A是B的35倍"
- **画面感白描**：把数据变成能看见的场景（"4S店挤满揣着现金的大哥，销售用鼻孔看人"）

### 4. 用梗与情绪：每1–2分钟一个"调味料"
硬核内容会让人疲劳，需要节奏性投放：网络热词、自嘲、拟声词、辛辣吐槽、股民黑话。共享的梗/黑话库见 `references/meme-and-slang-library.md`。原则：**梗服务于把概念讲清楚，不为搞笑而搞笑。**

### 5. 节奏：长句铺信息，短句砸结论
- 长句铺陈 → 3–5字短句爆破（"……而是自由落体了。""扶不起来的。"）
- 用"是不是/对不对/对吧"做反问停顿，制造"点头节奏"
- 递进句式："这还没完→再加一层""再比如…再再比如…"

### 6. 收尾：必须有一个落点
绝不干巴巴结束。三种落点任选：
- **升华到规律/认知**（把个案抽象成可迁移的道理）
- **情绪落点**（命运感/激励/清醒/祝福）
- **行动/互动**（留思考题、引导关注往期、一句俏皮话软着陆）

### 7. 起标题：把好奇缺口写进标题
公式：**【惊人数字 or 反差比喻】+【主体】+【悬念问号 or 反共识断言】**。
高频词：竟然、凭什么、到底怎么回事、你敢信、为什么……反而……

### 8. 平台结算线（发抖音/小红书的脚本必须满足；2026-07 Bobby AI 账号实测）
- **25 秒结算线**：抖音人均观看 20~27 秒、与片长无关——核心增量（最大看点/反差结论）必须在前 25 秒交付完，之后是给 5% 深度观众的加餐。
- **第一句 = 硬信息**（主体+事件+数字），寒暄和铺垫直接吃 2s 跳出。
- **第二钩子**：3 分钟以上在 45%~60% 进度处用一组反差数字把人拽回来（实测跳过率峰值全在该区间）。
- **互动前置**：提问/押注放前 30 秒，结尾只做预告——结尾提问实测评论≈0。
- **Bobby AI 前置**（2026-09-10 起铁律）：前 30 秒内（理想 8~25 秒，hook 之后）一句工作痕迹句露出 Bobby AI——「用 Bobby AI 把数据整理了一下，有个很有意思的发现」，≤20 字带过就接发现；不占前 2 秒、不用「我查了」、国内不念功能清单；脚本里标 `【Bobby前置位 @ ~xx秒】`，制作阶段同拍出 app icon + 字标。片尾落版照旧。
- **小红书**注意力预算约为抖音 2 倍，5 分钟深度版只投小红书；标题必须有冲突/悬念（封面点击率实测差 3.4 倍）。
- 完整分发规则（发布时机/标题封面/数据回收表）：`agent/script/references/platform-douyin-xhs.md`

## 四、标准工作流（写一条脚本的步骤）

1. **确认三件事**（风格/长短/平台）——见第一节。
2. **读对应风格包**（`video-agent/script/styles/xiaolei.md` / `xiaolin` / `dailaoban` 之一）。如需要可同时读 `references/` 下的通用技法与梗库。
3. **搭骨架**：按风格包的结构模板列出分段提纲（钩子→…→收尾），先确认结构再填肉。
4. **填充**：逐段写，每段套用"通用方法论"的锚点检查（这段有没有类比/数字/画面？有没有梗？节奏对不对？）。
5. **起标题 + 钩子**：给3–5个标题候选 + 2–3个开场钩子候选。
6. **过自检清单**：跑该风格包末尾的 checklist。
7. **（可选）长短互改**：见各风格包的"长短视频改写法"。

> 产出格式建议：先给【标题候选】→【钩子候选】→【口播全文（分段标注：钩子/框架/主体/升华）】→【可选：分镜或字幕提示】。

### ⚠️ 免责声明（所有风格包通用，不可省略）

每条脚本交付时必须在**制作备注**中标明免责水印文案。视频成片画面上将全片常驻一行免责水印，文案按内容类型适配：

| 内容类型 | 免责水印文案 |
|---|---|
| 投教 / 科普 / 原理讲解 | 内容仅供科普 · 不构成投资建议 |
| 公司介绍 / 商业拆解 | 内容仅供信息参考 · 不构成投资建议 |
| 财报解读 / 数据分析 | 内容仅供信息参考 · 不构成投资建议 |
| 华尔街事件 / 金融历史 | 内容仅供科普 · 不构成投资建议 |
| 热点新闻 / 异动速读 | 内容仅供信息参考 · 不构成投资建议 |

脚本末尾口播收尾后，也要在文末写一行对应的免责声明（供落版/字幕用）。此规则不分风格包、不分平台，任何对外发布的财经视频脚本都必须带。

### ⚠️ 抖音合规强制关卡（所有风格包通用，不可省略）

凡是要发抖音/国内平台的脚本，定稿前必须过 `平台合规自检清单（自备）`：**话术黑名单**（赌博话术"翻身/回血/上岸"、收益承诺"稳赚/保本/躺赚"、绝对化用语"第一/首个/最强"、导流话术"加微信/进群/送资料"）+ **选题红线**（不荐股、不承诺收益、不编政策内幕、金融危机题材不用跳楼梗、整条不能是丧向基调）。交付说明附一行合规结论。硬约束，优先级高于任何风格要求。

## 五、新增账号风格包（给未来的你留的口子）

想加入新博主（比如又下载了新账号的转写），按这个流程：

1. **准备素材**：把该账号的口播转写放到一个目录（`.txt`，每条一个文件）；标题/数据在 `*_data.json`。若只有视频没转写，用本仓库 `rockflow/transcribe.py`（faster-whisper 本地转写）或 `bl speech recognize` 先转写一批高赞视频（建议8–15条，覆盖不同题材）。
2. **逆向拆解**：派一个分析 agent 通读14条左右转写，按"人设/钩子/结构/讲有趣手法/用梗/句式/选题标题/收尾/配方"九个维度产出风格报告（可直接复用本skill历史中给三个账号用的分析 prompt 模板）。
3. **生成风格包**：复制 `templates/new-account-style-pack.md`，按报告填好，存成新 skill：`.claude/skills/video-script-<账号slug>/SKILL.md`。
4. **登记**：在本文件第二节的调度表里加一行。

模板已列好所有必填小节和写作要求，照着填即可。
