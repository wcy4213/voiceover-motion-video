# 脚本风格包 · 小Lin说

> 一句话定位：**"华尔街投行出身的懂行学姐"** ——把别人讲不明白的硬东西讲得又清楚又有趣，站在观众这边手把手带你。招牌格式是"一口气了解X"。6–10分钟（多集可30分钟）。
>
> 通用方法论见 `video-agent/script/styles/framework.md`。本包写小Lin独有的配方。

---

## 一、人设与口吻
- **自称**：第三人称"小林"（"今天小林就来给大家梳理一下""能像小林这种把复杂东西讲清楚又有意思的人不多了"——半自夸半玩梗），也常直接用"我"。
- **称呼观众**：高频"你""你看""我跟你说""朋友们""咱/咱们"，把观众拉进同一阵营。
- **语气定位**：讲解者 + 朋友 + 略带学姐式自豪。主动管理评论区、降低观看门槛、为观众智商兜底。
- **可信度从哪来**：暗示"我是内行/我下了功夫"——"那天累死我了，把八九十年代的报纸都翻出来了""这期超硬核，我从半年前就开始准备"。

## 二、开场钩子模板（90%用反差/悬念/打脸认知）
- **A 认知反转**："可能在大多数人眼里麦当劳就是做快餐的，但我跟你说，它的业务核心其实是地产。"
- **B 矛盾体设问**："俄罗斯说到政治军事没人敢小瞧，但一提到经济，那似乎就没俄罗斯什么事了。"
- **C 新闻反常识**："养猪公司刚爆雷，股价却集体大涨了——为什么？"
- **D 造词/谐音引入**："你整天说性价比，但你听说过'新价比'吗？"
- **E 硬核宣言式**（为长视频打预防针）："朋友们今天这期太硬核了，各种知识点嘟嘟嘟往外冒，准备好了吗？"
> **"一口气了解X"招牌开法**：先点出对象"独一无二/错综复杂"，承认它难，再立"我来给你梳理清楚"，最后给退路"想看精简干货可以直接滑到最后"——既抬高价值又降低弃看。

## 三、结构骨架（高度故事化，非知识点罗列）
**(A) 公司/国家史诗型** → 悬念钩子→追溯起源→关键人物登场→冲突/商战高潮→拉回现状→升华启示。（LVMH、可口可乐VS百事、韩国/俄罗斯经济）
**(B) 机制/宏观解释型** → 反常现象→"为什么？"锁定一个核心变量→拆机制→类比落地→政策/出路→金句收尾。（猪周期、做空、日本经济）
> 关键：始终围绕**一个主角**（一个人/一家公司/一个变量）展开，让抽象经济变成"谁和谁斗、谁赢了、为什么"的剧情。背景"一丢丢带过"，把时间花在戏剧性冲突上。

## 四、把枯燥商业/宏观讲有趣的手法
1. **拟人化、戏剧化**：商战写成宫斗（阿尔诺"逼宫大戏"）、擂台积分（"1比0领先"）；国家写成有性格的人（日本"拧巴"、"利率曲线都躺平了"）。
2. **虚构教学案例**（王牌）：用"老王奶茶店+老李"把"融券做空"彻底口语化。
3. **数字具象化**："全球每天超10亿瓶饮料来自这两家""人均GDP是美国的35分之一""第一个1000店用18年，第五个只用一年半"。
4. **类比/打比方**：储备猪肉="猪肉的中央银行"；退出宽松="动物园待久的动物放回野外能不能活"；央行试探市场="谍中谍里阿汤哥碰机关"；杠杆+低息="干柴烈火"。
5. **时间线叙事+悬念前置**：先抛结局再倒叙（"就这一气之下，引发了长达百年的双雄商战"）；留扣子（"就是这招让百事翻身，这招就是价格战"）。

## 五、用梗 / 情绪方式
- **网络热词**："被尊称为快乐水""全民就业稳如老狗""卡办了就等于我去了""主打一个薄利多销"。
- **自嘲/玩人设**："能把复杂东西讲明白的人不多了，你也可以点个赞表示一下"（自夸+顺势求赞）。
- **拟声夸张**："嘟嘟嘟往外冒""哐哐涨""给这母猪累的呀"。
- **调侃式吐槽（带价值判断不说教）**："全球料是搬一个央行创新先锋奖，那肯定搬给日本央行——注意这是讽刺不是夸赞。"

## 六、标志性句式与口头禅
| 类型 | 表达 |
|---|---|
| 开场/强调 | 我跟你说 / 我给你说 / 你看 / 你别看 |
| 转折领起 | 但是呢 / 不过呢 / 那这边…另一边… / 问题是什么 |
| 设问推进 | 那它是怎么做到的呢 / 那为什么…呢 / 接下来发生了什么呢 |
| 卖关子递进 | 这还没完 / 还不够 / 有趣的地方才刚刚开始 / 我们再稍微深入一点 |
| 口语连接 | 对吧（极高频）/ 说白了就是 / 简单来说就是 / 总之呢 |
| 否定造反差 | 你以为…吗 No no no |
| 卖萌语气 | 哎呀 / 好家伙 / 一丢丢 / 哐哐 |
> **核心句法引擎**："先抛一个点 → 这还没完/还不够 → 再加一层"的螺旋递进。

## 七、节奏与信息密度（高密度但不让人懵）
1. **设问—回答驱动**：每步先替观众问出问题（路标）。
2. **显式编号框架**："两个支柱""三大原因""第一…第二…"提前给地图。
3. **先放结论/先给退路**："想看最精简干货可以直接滑到最后。"
4. **铺垫—反转微节奏**："你以为…吗？No no no""看起来百害无一利，但其实…"
> 详略由"戏剧性"而非"重要性"决定。

## 八、选题与起标题法
- **选题**：国家经济志（"一口气了解X经济"）、公司/商战、金融机制科普、借势反常识热点、亲历/独家探秘。
- **标题前缀体系（品牌资产）**：`一口气了解/看懂X`、`【硬核】/【硬核商业】`、`【完整纯享版】`、`【抖音独家】`、`【深度解读】`。
- **两套公式**：①悬念反差式（"你敢信？麦当劳竟然是个地产公司?!""不打广告的迪卡侬凭什么年入百亿？"）②品牌前缀+对象（"一口气了解俄罗斯经济"）。高频词：竟然、凭什么、到底怎么回事、你敢信。

## 九、收尾方式（必有情绪或认知落点）
1. **升华到底层规律**："这似乎是房地产逃不过的轮回，底层还是杠杆太高。"
2. **情怀升华**（亲历类）：把投行苦熬类比高考军训，落到对观众的激励。
3. **接地气玩笑软着陆**："你不如趁猪价低赶紧去吃九块红烧肉。"
4. **方法论打包送观众**（商业拆解类）：把玩法归纳成可套用清单。
5. **借势祝福式**："祝大家心情天天涨停，烦恼天天跌停。"

## 十、可复用配方
**通用配方**：钩子(反差/反常识) → 立人设+降门槛(承认硬核+承诺讲清+给退路) → 框架预告(几个支柱/原因) → 主体故事线(强主角+设问驱动+"这还没完"递进+每个抽象点配类比/案例/数字) → 玩梗调味 → 升华+俏皮话软着陆。

**招牌「一口气了解X」九步**：
1. 标题"一口气了解+对象"+悬念副标题。
2. 开场矛盾体（一句点出巨大反差）。
3. 预管理期望（承认复杂只挑重要又有意思的讲 + 管理评论区 + 给退路 + 顺势求赞）。
4. 历史"一丢丢带过"，不恋战。
5. 锁定主线人物/变量，整集围绕它。
6. 戏剧化展开（开挂/逆袭/宫斗/商战），转折前留扣子。
7. 每个专业概念配生活类比 + 一组对比数字。
8. 拉回现状 + 抽象出一条底层规律。
9. 俏皮收尾软着陆。

## 十一、长 / 短视频改写法
- **长→短(1–2min)**：抽一个最戏剧化的冲突点（如"价格战这一招怎么翻身的"），用"认知反转钩子→1个类比/案例→1句规律收尾"，砍历史回溯。
- **短→长**：把单点扩成完整史诗（补起源、关键人物、多轮冲突、现状、升华），加"两个支柱"框架和"这还没完"递进。
