# 把枯燥财经讲有趣 · 通用技法详解

三个账号共享的"降维"武器库。写任何风格时都可调用。每条都配真实例句（摘自三账号转写）。

---

## 技法 1：类比 / 打比方（最高频、最有效）

把陌生概念 = 观众熟悉的东西。好类比要"形神兼备"且生活化。

- 股票上市 = 开发商第一次把房子卖出去（小雷）
- 公司利润 = 火锅店：客人消费300，一锅菜成本100，毛利200（小雷）
- 做空 = 你跟邻居老李借来"老王奶茶店"的股票，高价卖掉，等跌了低价买回还他（小Lin）
- 央行储备猪肉 = "一个猪肉的中央银行"（小Lin）
- 央行退出量化宽松 = 动物园待久的动物放回野外能不能活（小Lin）
- 量子计算机的稀释制冷机 = "一个像热水器一样的大白罐子……不是热水器，而是一个大冰箱"（戴老板）
- 有效市场假说 = 剪刀石头布：能预判对手出什么，技术分析就失效了（小雷，自创类比）

> 技巧：类比讲完可以点一句"这个比喻是我自己想的，但我觉得非常精准"——既显原创又加深记忆（小雷常用）。

## 技法 2：拟人化 / 戏剧化

把公司、国家、行业、指标当"有性格、有命运的人"来写。

- "日本经济是又爱又恨，拧巴"（小Lin，整集围绕"拧巴"这个情绪）
- 阿尔诺夺LVMH = "明显一个太子跟皇上意见相左……直接上演了一季逼宫大戏"（小Lin）
- 可口可乐 vs 百事 = 擂台积分赛："老大哥毫无疑问以先发优势1比0领先"（小Lin）
- 保时捷被打败 = "一个假对手和三个真对手……小米负责佯攻，华为主攻，理想蔚来围攻，是一波联合绞杀"（戴老板，军事化拟人）
- 外卖大战 = "饱和攻击了京东，十面埋伏了美团"（戴老板）

> 把竞争写成"武侠/宫斗/战争"，观众就从"听经济"变成"看剧"。

## 技法 3：数字具象化（永远对比，永远场景化）

裸数字没有冲击力。三种处理：

- **对比涨跌幅**："羽衣甘蓝收购价从8毛涨到3.5元一斤，涨幅超300%"（戴老板）
- **倍数/换算**："人均GDP只有67美元，是美国的35分之一"（小Lin）；"现代人每摸一次脸，就要摸14次手机"（戴老板）
- **画面化大数**："全球每天超10亿瓶饮料来自这两家"（小Lin）；"研发人员从1万人涨到2.2万人"（戴老板）

---

## 技法 4：画面感白描

把数据/抽象判断变成能"看见"的镜头。

- "(保时捷4S店)红色柱子配黄色琉璃瓦，白色大理石地面，就差把'土豪'刻在门头上……挤满揣着现金的大哥，销售都是用鼻孔看人的。"（戴老板）
- "茶饮采购商住在农场里，叶子还没成熟就惦记着采收，生怕被别人抢走。"（戴老板）

---

## 技法 5：虚构教学案例（讲机制的王牌）

讲抽象机制时，造一个有名字的小案例，全程用它演示。

- "小猪"记账：100万现金 + 1000万的房 + 50万的车 − 830万负债 = 320万净资产，再无缝映射到公司资产负债表（小雷）
- "老王奶茶店 + 老李"演示融券做空（小Lin）
- "炮虎的村镇公司借一个亿，多拉A梦出面化债"（同类手法）

> 命名 + 拟人 + 全程贯穿，比抽象定义好懂10倍。

---

## 技法 6：设问—自答（讲解节奏的发动机）

每推进一步，先替观众问出来，再回答。问题=路标。

- "那它是怎么做到的呢？我总结归于两个支柱，先看第一个……"（小Lin）
- "为什么量子计算机要工作在绝对零度呢？这就需要简单了解一下……"（戴老板）
- "我们今天买一只股票，请问这个钱到底去哪儿了？"（小雷）

---

## 技法 7：层层递进 / "这还没完"

抛一个点 → "这还没完/还不够" → 再加一层。维持信息密度和期待。

- "首先他想尽办法让你嗨起来……这还没完……还有个绝招……但光有这个还不够……而且最关键的是……"（小Lin·迪卡侬）
- "你觉得这个有风险？那我再给你进化一下……再次进化……"（小雷·骗局拆解）

---

## 技法 8：反转 / 转折钩

每段埋一个"而/但/然而"或对照句，制造戏剧性。

- "这种不服输的风格，成就了他，也吞噬了他。"（戴老板）
- "灰溜溜那是真灰溜溜，但是斩却没有真斩。"（戴老板）
- "你以为韩国要立刻崛起了吗？No no no。"（小Lin）

---

## 技法 9：揭底牌信号词

要抛"真相/本质"前，用信号词提示，观众会竖起耳朵。
"其实……" / "说白了……" / "答案非常简单/残酷……" / "注意了……" / "这个可能颠覆你的想象……"
